2. 실제로 돈을 쓸 순서
첫째, 무료 공개자료와 협력 가능한 보유자료를 확인하고 부족한 항목을 정한다. 유료 자료는 일부 샘플에서 시편 ID, 하중·주기·시간, 균열 관측·검출 기준이 있는지 먼저 확인한다. 자료 이용권에 상업적 평가·비공개 보관·파생 결과의 사용이 포함되는지도 계약 전에 확인한다. 다운로드 파일 수가 많다는 이유로 피로 개시 표본이 충분하다고 판단하지 않는다.

둘째, 원자료 구매·정제용 200만원을 보전한다. 보완실험 100만원은 기존 기록만으로 해결되지 않는 특정 판정·동기화·보정 관측에 사용한다. 전체 신규 피로시험의 가격이나 완료를 이 금액으로 확약하지 않는다. 필요한 견적이 100만원을 넘으면 가장 중요한 추가 관측 하나로 좁히거나 자료보유기관과 협력한다.

셋째, 평가용 시편·조건은 보정에 쓰지 않고 남긴다. 독립 평가 150만원은 그 자료의 사용권, 기준방법 비교, 필요한 외부 검토에 배정한다. 원자료·보정·평가 항목 사이에서 같은 청구서를 중복 계상하지 않는다. 외부 검토를 발주하지 않았다면 개발자 시간의 가치를 현금 지출로 써놓지 않는다.

넷째, 토큰 사용은 두 서비스 합계 6개월 200만원 이내에서 월별로 관리한다. 구독에 포함된 사용량, 추가 크레딧과 API 청구를 구분한다. 입력·출력·캐시 토큰과 모델별 단가, 실제 원화 결제액을 기록한다. 구독료를 낸 계정의 포함 사용분을 API 사용료로 한 번 더 더하지 않는다. 월 정액 한도로 살 수 있는 토큰 수는 모델·출력·캐시에 따라 달라진다. 과금되는 도구 호출·세금·환전 수수료도 해당 한도에 포함한다.

다섯째, GPU 150만원은 대표 작업을 클라우드에서 실행해 시간·메모리·요금을 측정한 뒤 쓴다. 개발장비 구매는 부속품·저장장치·전원·배송 등을 포함한 견적 70만원 이내에서만 검토하며, 구매할 경우 계산비가 최소 80만원 남는다. Jetson은 가벼운 전후처리·로컬 추론용 후보이고 대규모 FEM/FVM·전체 GPU 가속을 이미 검증한 장비로 쓰지 않는다. 장비가 맞지 않으면 현금 GPU 150만원 전부를 클라우드 계산에 둔다. Claude/Codex의 원격 서비스 이용료가 GPU 장비로 없어지는 것은 아니다.

4. 지원 크레딧과 수익모델
D2SF 공지의 GPU·클라우드 500만원은 위 현금 1,000만원과 별도다. 사용 가능한 서비스·기간·결제계정을 확인하고, 크레딧으로 처리한 비용을 현금 지출로 다시 잡지 않는다. Claude·Codex 토큰이 지원 크레딧으로 자동 지급된다고 가정하지 않는다.

무료: 소규모 프로그램·모델·결과 업로드와 보기, 기본 단위·메시 검사, 사용자 소재상수 입력, 기본 메싱과 제한된 계산량.
유료: 큰 비공개 프로젝트와 협업, 국부 세분화·메시 개선·수렴 비교, 실험자료 기반 소재 보정·맞춤 모델, 배치·조건 탐색·GPU 계산, 상세 비교·보고서.
가격: 기관용 구독에 기본 저장·계산량을 포함하고, 초과 GPU/계산은 실행 전 비용을 보여주는 방식을 검토한다. 맞춤 소재 보정·솔버 연결은 별도 작업범위를 정한다. 가격은 고객평가와 실제 원가를 본 뒤 결정한다.

업로드는 프로그램 소스·실행 스크립트·모델 입력·결과·로그와 버전을 함께 등록하는 경로와 결과만 올리는 경로로 나눈다. 서버 실행은 지원 환경과 사용권이 확인된 작업만 별도 공간에서 처리한다. 유료 사용 여부와 무관하게 기본 단위·검증 상태 표시는 유지한다. 이 기능들은 현재 개발계획이며 구현·판매 실적이 아니다.
