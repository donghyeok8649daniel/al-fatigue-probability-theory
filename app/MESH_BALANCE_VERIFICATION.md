# 메시·면하중 수정과 실제 검증 — 2026-09-16

## 변경

- 응력 입력란은 초안이다. 3D 해석에서 저장한 면하중만 외력을 만든다.
  미지정 면은 견인력 0이고, 하중이 하나도 없으면 외력이 0인 시편을 계산한다.
  모델의 열적 확률 진화는 유지한다. 명시적인 국소 전용 PDE는 입력 응력을 사용한다.
- 면하중 탭에 확인 시각, 합력 XYZ [N], 합토크 XYZ [N·mm], 필요한 반대
  합력·토크, 지정/미지정 면 수를 표시한다. 사용자가 선택한 면에 적용하는 평형
  보정은 미리 확인하고 적용하며 별도로 해제할 수 있다.
- 메시 생성 전 시간 표본에서 평형을 검사하고, 실제 PDE가 하중을 평가하는
  시각에도 검사한다. 사전 표본 검사를 전 시간에 대한 상징적 증명으로 제시하지 않는다.
- 기본 TetGen 결과가 생성 실패·퇴화 요소·잘못된 경계면 등을 포함하면 입력
  표면 삼각형을 보존하는 방식으로 한 번 재시도한다. 강성 조립 전에 요소,
  체적, 원본 면별 면적, 경계 소유 요소를 검사한다. 불량 요소를 삭제하지 않는다.
- 요소 응력은 첫 절점에 대한 상대 변위를 미분한다. 공통 변위를 상쇄하는
  소수점 손실을 줄이고 응력 복원용 6×12 행렬 생성을 없앴다. 같은 선형 탄성이며
  강성·CG 허용 오차·확률 PDE·물리적 하중을 변경하지 않는다.

## 실제 사용자 STL의 기본값 오류

사용자는 목표 길이를 직접 입력하지 않았다고 답했다. 코드 기본값인 표면/체적
각 3 mm에서 `fatigue_specimen.stl`로 동일 오류를 재현했다. 원본은 2,882면,
3 mm 표면 분할은 14,942면이다. 첫 TetGen 결과는 1,144,229사면체에 체적 0인
요소와 원본 면적 불일치를 포함했다. 입력 누락으로 판정하지 않았다.

최종 코드의 재시도 결과:

- 12,192절점 / **58,712사면체**, 전체 체적 8,709.690656311075 mm³.
- 원본 14,942개 면의 면적과 저장 하중 대응을 보존했다.
- 6성분 균일 응력 patch 검증의 최대 오차 **1.1370e-9 MPa**,
  실제 `||Ku-f||/||f||` **4.1804e-13**.
- 실제 X축 양 끝면 100 MPa 하중 해석의 평형 잔차 **2.2410e-12**.
- 체적 목표 h³/6=4.5 mm³에 대해 실제 최대 요소 체적은 5.6889 mm³다.
  표면 분할 제약 아래 목표 크기가 모든 요소에서 보장되는 것은 아니다.

닫힌 형상이라는 판정만으로 모든 입력 STL의 자기 교차나 품질 문제가 해결된다고
주장하지 않는다. 두 경로 모두 실패하면 원인을 구분한 오류를 표시한다.

## 기존 한도를 넘는 실제 실행

- 표면 목표 0.4 mm: **617,032삼각형 / 308,518절점**, 최대 변 0.3998003 mm.
  원래 면적 3,897.0034722507 mm²와 체적을 보존했다. 이는 표면 분할 검사다.
- 원본 표면의 체적 목표 0.4 mm: **1,624,083사면체 / 293,991절점**을 생성하고
  6성분 균일 응력과 실제 양 끝 하중을 계산했다. 사면체 개수는 이전 한도를 넘는다.
  새 절점 상한 120만이나 사면체 상한 600만 전체를 실행한 것은 아니다.
- 기본 CG rtol=1e-11의 균일 응력 최대 오차는 **1.21865e-5 MPa**,
  전체 요소의 99%는 **9.16081e-8 MPa 이하**, 실제 평형 잔차 **5.60286e-10**다.
- 추가 진단에서 정한 엄격한 최대점 1e-5 MPa 기준은 매우 얇은 **2개 요소에서 미달**했다.
  처음 진단의 assertion 실패를 숨기지 않는다. 정확한 선형 변위를 넣었을 때도
  원래 응력 복원은 7.87966e-6 MPa, 상대 변위 복원은 2.52139e-6 MPa의
  산술 오차가 남는다. 이 메시의 가장 얇은 요소는 체적 2.27425e-11 mm³다.
- 같은 시스템에서 CG rtol=1e-13으로 추가 58회 푼 별도 대조는 최대 응력 오차
  **8.69801e-6 MPa**, 평형 잔차 **2.03561e-10**로 위 추가 기준을 통과했다.
  생산 CG를 이 설정으로 조용히 바꾸지 않았다. 이 대조를 기본 설정 결과로 제시하지 않는다.
- 최종 기본 설정의 실제 양 끝면 100 MPa 하중은 CG 128회로 완료했고,
  평형 잔차 **4.89813e-9**, 요소 σxx 범위 **8.54864~439.02965 MPa**다.
  이 응력 범위를 메시 수렴한 국소 최대 응력으로 인증하지 않는다.

자원 한도 확대, 방정식 잔차 검사와 공간 수렴/피로 확률의 물리적 검증은 별개다.
위 대형 실행은 역학 검사이며 162만 개의 독립 확률 PDE를 풀었다는 뜻이 아니다.
공간 확률은 기존과 같이 실제 응력 이력의 대표 PDE를 쓰고 표본 오차를 기록한다.
