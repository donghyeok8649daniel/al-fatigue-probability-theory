# 3D 면하중 평형, 국소 PDE, 체적 위험도

## 실행 방법

1. 닫힌 STL/OBJ를 가져오거나 원통을 만들고 표면 메시를 준비한다.
2. 면하중 탭에서 실제 XYZ 방향에 맞는 대칭 응력 텐서를 저장한다.
   각 면의 견인력은 `t = sigma n`이다. 여러 면하중은 더해진다.
   응력 입력란은 저장 전까지 초안이다. 미지정 면은 외력 0이고, 아무 면에도
   저장하지 않은 시편은 무하중이다. 무하중에서도 모델의 열적 확률 진화는 유지한다.
   예를 들어 **Z축 인장**은 `sigma_zz`에 하중을 넣고 양 끝면에 같은 텐서를
   각각 저장한다. 두 끝의 바깥 법선이 반대여서 실제 힘은 서로 반대가 된다.
   기본 텐서는 `sigma_xx`이므로 Z축 끝면 인장으로 사용하려면 바꾸어야 한다.
3. 양 끝 하중을 직접 평형으로 만들거나 기존의 평형 보정을 적용한다.
   입력에서 승인한 보정만 사용하며 불평형 하중을 몰래 제거하지 않는다.
   면하중 탭에서 확인 시각을 입력하면 합력·합토크와 필요한 반대 값을 볼 수 있다.
   보정은 선택한 면에 외력을 추가하는 것이며 별도 버튼으로 해제할 수 있다.
4. 조건 설정의 **3D 확률 투영축 e**를 지정한다. Z축 예제는 `0 0 1`이다.
   해석 탭에서 E, 포아송 비, PDE 공간 샘플 수를 확인한다. 기본 ν=0.33은
   편집 가능한 등방 탄성 가정이며 이 프로젝트에서 적합된 재료 상수가 아니다.
5. 해석 탭의 **체적 메시 목표 길이 [mm]**를 지정하고 **3D 면하중 + PDE 해석**을
   실행한다. 이 길이는 시편 길이가 아니라 체적 요소의 크기 입력이다. 표면 메시
   크기와 독립적이며, 값을 바꾼 다음 3D 해석만 다시 실행하면 된다. 저장된 면하중은
   유지된다. 국소 전용이 꺼져 있으면 기본 해석 버튼도 이 경로를 사용한다.
   명시적으로 국소 전용을 선택한 독립 PDE만 면 지정 없이 입력 응력을 사용한다.
6. 지도에서 축응력, 전체 응력 성분, 국소 확률을 선택한다. 체적 위험도에는
   외부의 **상관체적 V_c [mm³]**를 입력한다. 절단 슬라이더는 내부 사면체를
   보여 준다. 색상/시각/절단/V_c/언어 변경은 저장된 결과의 표시·후처리다.

열려 있던 이전 프로세스에는 새 코드가 자동 로드되지 않는다. 작업을 저장하고
UI를 다시 열어야 한다. `.ftgsim`은 체적 메시, 응력 기저, 시간 계수, 국소 PDE
이력과 V_c 입력을 저장한다. 불완전하거나 체적이 잘못된 배열은 복원 시 거부한다.

## 기계적 문제와 단위

`solid_mechanics.py`는 등방 작은 변형 선형 탄성의 별도 연속체 근사다.
정적 외력 전달을 계산하며 원자적 LJ/Bessel 에너지나 SG generator는 바꾸지 않는다.

```text
div sigma = 0                          in Omega
sigma = C(E,nu) : sym grad u
sigma n = t                           on boundary
integral t dA = 0
integral (x-x0) cross t dA = 0
```

길이 mm, 응력 MPa=N/mm², 힘 N, 토크 N·mm다. 선택 삼각형의 면적과
중심에서 힘·토크를 적분한다. 토크는 길이로 나누고 두 잔차를 표면 힘 크기
합으로 정규화한다. 상대 허용 오차는 1e-9다. 실제 시간 식을 평가하는 각 시각에
두 조건을 검사한다. 유한 시각 검사는 모든 실수 시각에 대한 상징적 증명은 아니다.
메시 생성 전에는 해석 구간의 17시각과 각 하중의 첫 주기 1/4 간격 시각을
추가 검사해 흔한 불평형을 일찍 알린다. 이 사전 검사가 실제 시각 검사를 대체하지 않는다.

닫힌 일관된 표면에서 TetGen 0.8.3으로 1차 사면체를 만든다. 목표 길이 h는
TetGen의 체적 목표 `maxvolume=h³/6`에 사용된다. 경계 형상/분할 제약 때문에
실제 일부 요소가 이 체적 목표를 넘을 수 있으며 모든 변의 길이 h 이하도 보증하지
않는다. 결과의 `cell_volumes_mm3`와 `target_mm`로 실제 분할을 감사한다.
분할된 경계면에는 원본 삼각형 표지가 유지되며, 각 원본 면의 총 면적과
전체 체적을 독립 검사한다. 일정 견인력을 경계 삼각형의 세 절점에 A*t/3씩
분배하면 원래 힘과 중심에 대한 토크가 보존된다.

기본 분할이 실패하거나 유효하지 않은 요소/경계면을 만들면 `nobisect=True`로
입력 표면 삼각형을 보존하여 한 번 재시도한다. 품질 분할과 같은 체적 목표는
계속 요청한다. 두 경로 모두 강성 조립 전에 비퇴화 요소, 전체 체적, 원본 면별
면적, 경계 소유 요소를 검사한다. 실패 요소를 삭제하거나 허용 오차를 늘리지 않는다.
`meshing_info`에 재시도 이유, 경로와 실제 최소/최대 요소 체적을 저장한다.
이 검사는 기하학·하중 전달 일관성 확인이며 공간 수렴 인증은 아니다.

현재 체적 한도는 총 1,200,000절점 / 6,000,000사면체다. 표면은 2,000,000삼각형,
STL/OBJ 가져오기는 512 MiB까지다. TetGen `steinerleft`는
**추가 절점 수**이므로 `1200000-입력절점수`로 지정한다. 생성 중 이 예산을 소진하면
중단 결과를 수렴한 메시로 채택하지 않는다. 한도 오류는 실제 생성 수와 설정값을
표시한다. 긴/좁은 표면 삼각형의 품질 분할이 지배하면 h를 늘려도 개수가 줄지
않을 수 있다. 표면을 삭제하거나 임의로 거칠게 만들지 않는다.

사면체 안의 변위는 1차, 변형률과 응력은 일정하다. 공학적 전단 변형률을 쓰는
Voigt 순서는 `[xx, yy, zz, yz, xz, xy]`이다.

```text
K_element = V_element B^T C B
K u = f
```

자유 물체는 강체 평행이동 3개와 회전 3개를 갖는다. 절점의 강체 운동 벡터를
QR로 직교화한 R을 써서 다음 문제를 푼다.

```text
[ K/E  R ] [ u      ] = [ f/E ]
[ R^T  0 ] [ lambda ]   [ 0   ]
```

실제 계산은 위의 같은 문제를 메모리를 적게 쓰는 방식으로 푼다.

- 80,000절점 이하: `R^T`의 pivoted QR로 독립적인 6개 임시 기준 자유도를 고른다.
  `f_perp=f-R(R^T f)`에 대해 나머지 강성 행렬을 sparse LU로 풀고,
  `u <- u-R(R^T u)`로 원래 직교 조건을 복원한다. 누락된 여섯 평형식도
  `R^T(Ku-f_perp)=0`과 선택한 6행의 가역성으로 성립한다.
- 더 큰 메시: PyAMG 5.3.0의 smoothed aggregation에 강체 운동 6개를 후보로 주고
  projected conjugate gradient를 쓴다. 행렬과 preconditioner 양쪽에
  `Q=I-RR^T`를 적용한다. 상대 반복 허용 오차는 1e-11, 최대 2,000회이며,
  실패한 해를 결과로 채택하지 않는다. 최종 실제 `Ku-f`도 별도로 확인한다.
- 두 방법 모두 `R(R^T f)`가 보조 기저의 gauge 반력이다. 불평형인 보조 기저를
  포함하여 기존 전체 증대 행렬과 대조한다. 실제 입력 하중의 힘·토크 평형 검사는
  그대로 유지하며, diagonal regularization이나 물리적 고정점은 추가하지 않는다.

요소 강성 조립은 16,384사면체씩 계산하고 희소 행렬을 이진 트리로 합친다.
전체 요소의 12×12 강성/행/열 배열을 한꺼번에 만들지 않는다. 요소마다 12개
형상함수 미분만 보관하고 B와 자유도 배열은 조립 구간에서 확장한다.
응력 복원은 첫 절점에 대한 상대 변위를 먼저 미분한다. 이는 같은 선형 변형률이지만
아주 얇은 요소에서 공통 변위의 상쇄 오차를 줄이며 6×12 B 배열을 만들지 않는다.
경계 소유 요소는 TetGen face2tet 연결에서 읽고 실제 세 꼭짓점의 포함을 검사한다.
불변 표면의 면적·방향·폐곡면 판정·해시를 재사용하며, 외부로 반환한 배열의 수정은
캐시에 영향을 주지 않는다. 하중 기저 배열도
사전 할당하여 이중 보관하지 않는다. 저장은 배열을 ZIP에 직접 스트리밍하고
읽기도 최종 배열에 채우며 SHA-256을 검사한다. 프로젝트 한도는 비압축 16 GiB다.
한도 안의 모든 형상·하중 조합에 일정 메모리/시간이나 수렴을 보증하는 것은 아니다.

`R^T u=0`은 절점 유클리드 내적에서 변위의 기준을 정하는 조건이다. 고정 지점이나
물리 지지대를 추가하는 것이 아니다. 평형 하중에서는 이 조건의 가상 반력이
수치 잔차 이내로 사라진다. `norm(Ku-f)/norm(f) <= 1e-7`을 별도로 검사한다.
연결되지 않은 물체는 각각 6개 조건이 필요하므로 현재 경로에서 거부한다.

각 저장 하중의 6개 텐서 성분에 대한 기저를 한 번 풀고 선형 결합한다. 개별
보조 기저는 불평형일 수 있지만 실제 결합된 힘·토크와 선형 잔차는 매번 검사한다.
기존 평형 보정은 선형 연산자로 각 기저에 적용하여 시간 의존성을 유지한다.
한 시각의 보정값을 모든 시각에 상수로 복사하지 않는다.

## 3D 응력에서 국소 확률로

전체 3D 응력 텐서를 보존한다. 기존 reduced N=1 확률 모델에는 사용자가 지정한
단위 축의 부호 있는 `sigma_e = e^T sigma e`를 전달하고 기존 `f*=kappa*sigma_e/E`
변환을 그대로 사용한다. 기본 초기 Gibbs preload도 실제 t=0 응력으로 초기화한다.
von Mises는 표시용이며 확률 입력이나 소성 모델로 대체하지 않는다.

해석 탭의 **초기 상태**는 다음 두 준비 과정을 명시적으로 구별한다.

- 초기 하중에서 평형 준비: 기존 기본값이다. 각 위치의 실제 t=0 응력에서
  주 우물의 조건부 Gibbs 밀도를 준비한다.
- 무하중 평형 준비 후 하중 적용: 0 응력에서 준비하고 t=0부터 지정 하중을 가한다.
  초기 opening 경계를 이미 넘은 질량은 기존 흡수 기록에 들어간다. 전부 흡수되면
  생존 ensemble의 변형률은 정의되지 않으므로 NaN으로 남긴다.

초기 basin이 비면 현재 모델의 opening 임계력 범위와 비교해 물리적 모델 basin
부재와 격자 미분해를 구별한다. 존재하지 않는 하중 평형은 격자를 늘려 만들 수 없다.
입력 하중을 줄이거나 준비 과정을 명시적으로 바꿔야 하며 자동 변경하지 않는다.
예를 들어 이 작업에서 검사한 목 시편의 단부 평균 1200 MPa는 최고 국소 평균
약 5214 MPa로 전달됐다. 기본 TwoRowLJ에서 모든 normal opening basin이 사라지는
힘의 환산값은 약 4199 MPa였다. 이 수치는 **현재 reduced 모델의 한계이며 실제
알루미늄의 항복·파단 강도가 아니다**. 1500 MPa 진폭은 t=0 이후 이력에 들어간다.
초기 상태 선택과 실제 preload는 결과 및 프로젝트에 저장한다.

공간 샘플 수 2–64는 국소 PDE 실행 수의 상한이다. 17–129개 선택 시각에서 계산한
사면체별 부호 있는 응력 이력의 최대 차이를 거리로 사용하여 대표 요소를 고른다.
각 대표에서는 실제 시간 식으로 기존 PDE를 독립 실행한다. 같은 설정의 에너지
모델과 opening 표, 고정 응력 환산 계수만 공유하고 밀도·시간 이력은 공유하지 않는다.
다른 요소에는 가장
가까운 대표 이력의 확률을 배정한다. 같은 응력 이력은 요소 체적과 무관하게 같은
PDE를 공유한다. 표시 시간축만 선형 보간하며 원래 적응 시간 기록도 보존한다.
실제 생존 density가 소진되어 조기 종료했다면 이후 흡수 확률을 일정하게 연장하고
그 사실을 원시 이력에 표시한다. 중단된 미완료 해석으로 지도를 만들지 않는다.

**이 공간 샘플 근사는 수렴 미인증이다.** 요소마다 샘플 시각에서의 응력 이력
불일치를 저장·표시한다. 이 값은 연속 시간 전체의 오차 상한이나 확률 오차 상한이
아니다. 대표 수, 시간 해상도, 사면체 메시와 PDE a/s/dt를 독립적으로 정밀화해야 한다.
메시 체적을 확률에 곱해서 국소 응력 효과를 만들어내지 않는다.

기존 주 곡선·진단은 첫 대표 요소의 국소 PDE다. 시편 전체 확률로 부르지 않는다.
공간 결과에는 기존 단일 국소 수렴 인증 버튼을 적용하지 않는다.

3D 해석 중에도 이 첫 대표 PDE의 실제 흡수 기록을 주 창에 전달한다.
Solve의 `A_c > 0`, `A_stressed >= 0` 입력이 있으면 외삽 숫자와 곡선도
계산 중 갱신된다. 다른 대표의 시간 이력을 이어 붙이지 않으며, 전체 공간
지도의 색상은 모든 대표 계산이 완료된 뒤 표시한다. 면적 외삽은 첫 대표의
확률에 독립·등가 영역 가정을 적용한 미인증 값이지 비균일 시편의 적분값이 아니다.
저장 파일을 열 때는 원래 국소 이력과 복원한 면적 입력으로 외삽을 다시 계산한다.
PDE를 재실행하지 않으며 수렴 인증 상태도 올리지 않는다.

## 체적당 위험도와 요소 확률

국소 개시 확률 p에서 외부 통계 가정으로 다음을 정의한다.

```text
h_v = -log1p(-p) / V_c                  [mm^-3]
P_element = -expm1(-h_v * V_element)    [1]
P_1mm3 = -expm1(-h_v * 1 mm^3)         [1]
```

`h_v`는 **체적당 누적 hazard**이며 시간당 발생률이 아니다. `P_element/V_element`는
확률이 작지 않을 때 요소 분할에 의존하므로 체적당 표준화 정의로 쓰지 않는다.
균일한 h_v에서 요소를 둘로 나누면 h_v가 그대로이고 두 생존 확률의 곱이 원래
요소의 생존 확률과 같다. `P_1mm3`는 모든 위치를 같은 크기의 체적으로 비교한다.
`P_element`는 실제 사면체 크기를 반영하므로 같은 재료 위험도에서도 달라질 수 있다.

**V_c는 현재 미보정, 기본값 공란이다.** 독립·등가 통계적 체적이라는 추가 가정이며
2D 원자 상태의 확률이 실제 3D 상관체적 하나에 대응한다는 검증은 아직 없다.
`V_element`, 원자 체적, 상관 면적 A_c에서 임의로 계산하지 않는다. V_c는 기계적
응력, 에너지, 확률 density, strain, mobility, 시간 보정에 들어가지 않는다.
국소 수치 하한 이하의 신호도 확대할 수 있으므로 모든 체적 지도는 **미인증 외삽**이다.
단일 실행 수치 하한도 함께 표시하며 material/kinetic/fatigue 승인을 의미하지 않는다.

희귀 확률과 큰 체적 비에서도 안정적이도록 log 영역과 log1p/expm1을 사용한다.
p=0은 모든 체적에서 0, p=1은 무한 hazard와 요소 확률 1이다. 무한 hazard는
자홍색으로 표시한다. 절단은 축 e를 따른 요소 중심의 부분집합 경계이며 정확한
평면 절단 재메시는 아니다. 내부 공통면을 제거하고 각 보이는 면에 소유 요소 값을 쓴다.

## 검증과 적용 한계

`test_solid_mechanics.py`는 모든 6개 일정 응력의 patch test, 일/에너지,
강체 기준과 가상 반력, 여러 평형 하중, 합력 0/토크 nonzero의 거부,
시간 의존 보정의 직접 solve 대조, 실제 3D→PDE 연결과 저장/복원을 검사한다.
`test_volume_risk.py`는 체적 분할 불변성, 생존 확률 곱, 수치 극한과 V_c 거부를
검사한다. UI 회귀는 기본 버튼의 3D 선택, 체적 지도, 절단, 언어, 저장/복원,
표시 변경 시 PDE 미실행을 검사한다. 최종 실행 결과는 CURRENT_WORK_HANDOFF.md 참조.

별도 실제 합성 목 시편(24각형, 끝 반지름 5 mm/목 2.5 mm, 길이 60 mm)의
양 끝에 100 MPa를 가한 3D FEM 결과:

| 목표 h [mm] | 사면체 수 | 목 평균 σzz [MPa] | 끝부 평균 σzz [MPa] | 상대 선형 잔차 |
|---:|---:|---:|---:|---:|
| 5 | 34,546 | 400.00217 | 100.00502 | 2.80e-13 |
| 3 | 34,441 | 399.99873 | 100.02505 | 3.82e-13 |
| 2 | 38,889 | 399.99921 | 100.01918 | 5.45e-13 |

목 z=25–35 mm/끝부 z=1–5 mm의 요소 응력을 체적으로 가중 평균했다.
목 단면적이 1/4이면 같은 축력에서 평균 축응력이 약 4배가 된다. TetGen의 품질
조건 때문에 요소 수가 h에 대해 단조 증가하지 않았으며, 이 비교만으로 상세
어깨 응력집중이나 확률 수렴을 인증하지 않는다. 사용자의 특정 STL 검증도 아니다.

### 가져온 fatigue_specimen.stl의 한도 오류 재현과 수정

별도 사용자 파일에서 표면 2,882삼각형/1,443절점, 면적3897.0034722507 mm²,
체적8709.6906563111 mm³를 확인했다. 면적은 이전 사용자 화면과 일치했다.
기존 코드는 추가 절점 30,000개를 허용하면서 총 절점도 30,000개로 제한했다.
h=3/6/12 mm에서 각각110,032/112,593/112,593사면체와 **31,443절점**이 나왔고
모두 거부됐다. 이 경우 길이만 늘리라는 이전 안내는 해결책이 아니었다.

수정 후 h=3 mm에서50,480절점/209,439사면체로 실제 FEM을 완료했다.
6성분 일정 응력 patch test의 최대 오차5.890e-10 MPa/상대 잔차8.261e-13,
양 끝면100 MPa 축인장의 상대 잔차3.746e-12였다. 초기 큰 행렬 조립 버퍼는
LU 전에 해제한다. 선형 solve의 통과는 공간 메시 수렴이나 피로 보정이 아니다.
이 메시의 실제 최대 요소 체적은6.42133 mm³로 지정 목표4.5 mm³보다 컸다.
목표값 입력과 실제 모든 요소의 목표 충족을 구별한다. 이번 오류 수정 검사는
이 파일의 정적 역학이며 사용자의 전체 시간 하중/PDE를 새로 완료했다는 뜻이 아니다.

### 메시 용량 확장 후 실제 파일 검증

동일 STL에서 h=3 mm의 같은 50,480절점/209,439사면체 정적 검사를 새 직접 해법으로
약11.12초에 완료했다. 이전 약109.63초와 비교된다. 6성분 patch 최대 오차
4.168e-9 MPa, 양 끝면 축인장 상대 잔차4.605e-12다.

체적 h=0.5 mm에서는 **174,593절점 / 918,741사면체**를 생성했다. 다중격자 준비까지
48.57초, 6성분 일정 응력과 양 끝면100 MPa의 두 해까지99.11초였다.
patch 최대 오차4.443e-8 MPa / 상대 잔차5.916e-12 / 37회 반복,
양 끝 하중 상대 잔차1.018e-11 / 38회 반복이다. 최고 working set은
2,370,027,520 bytes, 최고 process commit은3,485,151,232 bytes였다.
같은 크기의 직접 LU 시험은 process commit 약18.35 GB로 증가하여 진단 프로세스를
중단했고, 이 비교를 완료된 직접 해석으로 보고하지 않는다.

별도의 표면 h=1 mm 분할은113,698삼각형을0.73초에 생성했다. 최대 변 길이
0.995025 mm, 면적3897.003472250733 mm², 체적8709.690656311073 mm³다.
표면 h=.5 mm도449,088삼각형/4.76초, 최대 변.49751217 mm로 완료했다.
긴 변만 공유 중점으로 나누며 작은 면을 전체 균일 분할하지 않는다. 50,000면을 넘는
화면에서는 삼각형 테두리 선만 생략한다. 모든 면의 형상·선택·응력 값은 유지한다.
대형 메시의 PDE/저장·복원과 최종 회귀 결과는 CURRENT_WORK_HANDOFF.md를 참조한다.

같은918,741요소에서 별도 짧은100±20 MPa 양 끝 하중(1000/model-time, .05cycles),
대표PDE2곳을 실제 계산하고 비압축331,521,384 B 결과를 저장/복원했다. 응력/확률
배열은 정확히 일치하며 전체210초였다. 이는 파이프라인 검증이며 대표2곳의 공간
수렴 인증이나 사용자의 전체 피로 하중 이력 재실행은 아니다. 전체 app145개와
하위 검사3개가 통과했다. 원래 에너지/PDE/physical-Hz gate는 바뀌지 않았다.

관성, 접촉, 큰 변형, 균열 뒤 하중 재분배, 다축 원자 전이 및 물리 Hz는 포함하지
않는다. 선형 탄성 응력의 연결 성공과 Al 재료/kinetic/실험 피로 보정은 별도 gate다.
