# 소재 선택과 실리콘 웨이퍼 설정

`Pre / 사전 조건` 상단의 **소재**에서 알루미늄(Al)과 실리콘 웨이퍼(Si)를
선택한다. 기본값은 Al이다. 소재는 Al 에너지 registry의 모델 ID와 별개다.

## 실리콘 웨이퍼 입력

- **도핑 사용**: 해제하면 의도적 도핑 없음. 캐리어/잔류 불순물 농도를 0으로
  가정하지 않는다.
- **도펀트 물질**: 붕소(B), 인(P), 비소(As), 안티몬(Sb).
- **도펀트 농도**: 도펀트 원자 수 기준 cm⁻³. `1e16`, `2.5E18`처럼 입력할 수 있다.
  캐리어 농도, 비저항(Ω·cm), 주입량(cm⁻²)을 이 값으로 해석하지 않는다.

공통 도펀트 목록은 [Siltronic의 polished-wafer 제품 설명](https://www.siltronic.com/en/products/polished-wafers.html)에
명시된 B/P/As/Sb를 기준으로 삼았다. 이것은 입력 선택지의 출처이며, 도핑에
따른 탄성·파괴 에너지·이동도 보정 자료가 아니다. 농도 기본값/자동 환산/물성
보간은 추가하지 않았다. 숫자는 유한하고 양수여야 하며 임의 물리 상한으로
clamp하지 않는다. 현재 한 종류의 도펀트와 하나의 농도를 저장한다.
공간 농도 분포, 공도핑, 활성화율은 모델링하지 않는다.

## 저장과 전환

`.ftgsim` v2의 `material` 항목에 소재와 도핑 입력 초안을 저장한다. 입력 중인
농도 문자열도 그대로 저장한다. 실제 `UIAnalysisConfig`로 만들 때만 유효한
숫자로 변환한다. 비활성 도핑 입력은 초안으로 보존하되 실제 구성에서는
`dopant_species`/`dopant_concentration_cm3`를 `None`으로 만든다.

Al↔Si, 도핑 켜기/끄기, ko↔en 전환은 PDE를 실행하지 않는다. Al 설정과
도핑 초안은 전환 후에도 남는다. 실리콘 선택 중에는 Al의 에너지·영률·시간
설정 폼을 숨긴다. 소재 항목이 없는 기존 프로젝트와 실행 설정은 Al로 복원한다.

실행 결과의 소재는 현재 수정 중인 입력과 독립이다. 결과 메타데이터,
계산 요약, 그래프에 **해석 소재**를 표시한다. Al 결과를 가진 프로젝트에서
입력을 Si로 바꿔 저장해도 이전 결과는 Al이다. 소재를 Si로 바꿔 붙인 결과는
현재 지원되는 실행 결과로 복원하지 않는다.

## 실행 상태

Si는 **설정 저장 가능 / 해석 준비 중**이다. 실리콘·도핑에 대응하는 검증된
에너지 모델, 동역학, 흡수 경계가 아직 연결되지 않았다.
[별도 Si 탐색 결과](../results/silicon_wafer_feasibility/RESEARCH_MEMO.md)는
정적·수치 재사용 진단이며 도핑 물성 또는 웨이퍼 피로 보정이 아니다.

Si를 고르면 세 계산 버튼과 수렴검사를 비활성화한다. UI 콜백뿐 아니라 응력
환산, 국소 PDE, 축단면, 3D mechanics/PDE, 수렴검사 진입점이 모두 Al 모델
생성 및 체적 메시 작업 전에 소재를 검사한다. 준비된 Al 모델 전달로 이 검사를
우회할 수도 없다. Al kinetic calibration을 Si의 physical Hz로 사용하지 않는다.

Al 에너지/SG/이동도/응력 매핑은 유지한다. 기존 Al 보정의 한계를 소재 선택
기능이 해결한 것으로 보지 않는다.
