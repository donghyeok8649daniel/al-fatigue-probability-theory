# 축인장 단면 평균 reference

`axial_specimen.py`는 명시적으로 선택하는 1D 준정적 축인장 근사다.
여러 면하중·전단·XYZ 텐서는 [3D 경로](SOLID_MECHANICS.md)를 사용한다.

닫힌 일관된 표면 메시에서 선택된 전체 평면 끝면의 바깥 법선을 반대로 돌려
시편 안쪽의 축 e를 정한다. 반대 끝면과 같은 축선 위의 단면 중심을 확인한다.
각 절단면과 삼각형의 교선을 연결한 하나의 닫힌 다각형에서 실제 면적 A(x)를
적분한다. 삼각형의 표면적을 단면적으로 대신 쓰지 않는다. 정점에 정확히 걸리는
절단은 작은 기록된 거리만큼 옮긴다. 구멍, 분리 윤곽, 편심, 부분 끝면은 거부한다.

```text
N(t) = sigma_end(t) A_end
sigma(x,t) = N(t) / A(x)
f*(x,t) = kappa sigma(x,t) / E
```

같은 축력이 흐르므로 단면적이 작을수록 응력이 커진다. 지름이 절반인 목의
단면적은 1/4이고 단면 평균 응력은 4배다. 반대 끝면의 동일 크기 반력과 자유
측면을 가정한다. 현재 UI의 기본 평균/진폭은 선택된 끝면의 균일 축방향 견인력이다.

각 다른 응력 배율에서 기존 국소 확률 PDE를 독립 실행한다. 상대 1e-10 이내의
기하학적 roundoff만 동일 배율로 묶는다. 확률을 면적이나 응력 배율로 곱하지 않는다.
적응 시간 이력은 원래 값으로 보존하고 공통 표시 시각에서만 시간 보간한다.
원시 생존 질량이 모두 소진되면 이후 흡수 확률은 일정하게 연장하고 표시한다.
수치 질량 잔차와 희귀사건 하한은 물리 확률과 별도로 저장한다.

지도는 각 표면 삼각형 중심이 속한 단면 구간의 응력/국소 확률을 표시한다.
메시 hash로 결과를 연결하며 다른 메시가 되면 재해석을 요구한다. 면적 A_c와
상관체적 V_c는 이 응력 또는 국소 PDE에 사용하지 않는다. 체적 위험도 지도는
실제 사면체 체적을 갖는 3D 해석에서 제공한다.

어깨의 3D 응력집중, 굽힘, 접촉, 관성, 큰 변형 및 균열 뒤 재분배는 이 reference의
범위 밖이다. 임의 외력을 1D 하중으로 몰래 축약하지 않는다. 단면 평균 역학과
단일 실행 PDE 결과이며 공간/PDE/재료 수렴은 미인증이다. 물리 시간 gate는 그대로다.

`test_axial_specimen.py`에서 실제 면적, N 보존, 목 4배 응력, 강체 회전/이동,
길이 척도 변화, 표면 및 단면 정밀화, 잘못된 입력 거부, 실제 4배 하중 PDE의
독립 대조, 수치 하한과 저장/복원을 검사한다.
