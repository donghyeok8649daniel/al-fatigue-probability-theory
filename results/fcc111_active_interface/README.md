# Active-interface evidence: static research only

Use **audited_v2/** for the current candidates, consistently relaxed FCC
geometry, microscopic-area conversion and independent refinement studies.
The candidates fail physical readiness. They are not connected to the PDE.

The CSVs and images directly in this parent directory are preserved legacy
results from the underidentified calibration. Apparent agreement in any one
legacy plot is not a current validation certificate. The corresponding parent
summary.json marks them superseded.

audited_v2/opening_barriers.csv follows the first fixed-registry normal branch.
It does not supply a coupled slip/opening saddle or a dynamic event order.
Negative registry curvature at a constrained normal minimum is explicitly
recorded and precludes interpreting it as a stable two-coordinate minimum.

See solver_v1/FCC111_ACTIVE_INTERFACE_DERIVATION.md for the per-atom EAM
bookkeeping, energy/area normalization, and limitations.
