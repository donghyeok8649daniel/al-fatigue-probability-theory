# 현재 모델과 최초 개시 경로를 연결하기 위한 조건

## 지배방정식의 역할

정당화된 등온 Markov 좌표 q에서 같은 보존 확률 법칙을 사용한다.

    ∂t P = -∇q·J
    J = -M(q)[P∇qF + kBT∇qP]

P는 지정한 좌표 측도에 대한 확률밀도, F는 같은 측도에서 정의한 조건부
자유에너지, M은 기계 이동도다. 첫 균열 상태 B에 처음 도달한 질량을
A_abs로 누적하고 S=1-A_abs로 집계한다. 수치적으로 빠진 질량은 별도 잔차다.
도핑 배치가 고정이면 배치별 법칙을 먼저 풀고 준비된 배치 가중치로 생존을
평균한다. 전하가 유한 속도로 전환되면 전하별 확률과 전이 생성자를 유지한다.

현재 원자 계산은 이 식에 들어갈 Si의 상태·에너지를 검증하는 준비 단계다.
Al 기준의 q=(a,s)를 실제 Si 전체 시편의 완결된 좌표로 검증한 것은 아니다.
0 K 에너지 U, 유한온도 F, 실제 기계 M, 물리 초/Hz는 서로 다른 입력이다.
실제 Si의 B·전이 경로·F·M·물리 확률/수명은 아직 검증하지 못했다.

## 같은 8%에서도 원자 상태는 다르다

v11의 최초8%와10%를 거쳐 복귀한8%를 동일한 원자 번호로 비교했다.
`chord_geometry/summary.json`과 입력 SHA256이 아래 수치의 근거다.

- 강체 grip 좌표의 최대 차이: 0 Å.
- 자유216원자의 배치 차이: RMS1.054057 Å, 최대2.884706 Å.
- 저장 에너지 차이(복귀-최초): -9.719222938 eV.
- 잔여 자유원자 힘의 최대 벡터 크기: 최초0.000825047, 복귀0.000935926 eV/Å.

동일한 외부 변위가 동일한 내부 원자 상태를 뜻하지 않는다. 위 힘 잔차를
없어진 것으로 처리하지 않으며, 정확한 두 최소점이나 균열 상태의 증명으로
부르지 않는다. 고정 변위의 두 U를 비교한 것이므로 힘 제어의 다른 상태를
같은 방식으로 비교해서는 안 된다. 에너지 차이는 전이 장벽이나 열적 소산이 아니다.

## 직선 경로의 기하 감사

### 국소 곡률의 변형 방향을 비교한 결과

같은 고정부와 원자 번호의 Cartesian 좌표에서 두 완성 Hessian을 비교했다.
최저곡률 방향들의 제곱 내적은0.883568314, 부호를 구별하지 않는 각도는
19.951274도다. 이 값은 기하적 일치도이며 확률이나 불확실성 범위가 아니다.
최초 상태의 최저방향을 고정하면 곡률은 최초0.029470024에서 복귀0.097748274
eV/Å²로 커진다. 복귀 상태의 최소0.022821592는 다른 방향에서 얻어진다.
따라서 최소고유값 한 개의 감소를 모든 방향의 연화나 벌크 영률 감소로
해석할 수 없다. 개별 모드의 순서 교환과 부분공간 경계 gap도 저장했다.

양끝 위치 차이 d를 최초 상태의 U+g·d+dᵀHd/2에 넣으면 예측 에너지 차이는
+222.234825eV다. 저장된 실제 복귀-최초 차이는-9.719223eV다. 반대쪽에서도
국소식은+301.865825eV를 예측하지만 실제 최초-복귀 차이는+9.719223eV다.
총360원자 시편의 모델 에너지이며 per-atom 값이 아니다. 큰 유한 변위를
국소 이차식으로 이어 붙이는 것은 유효하지 않다는 직접 검사다. 이 외삽의
높이나 오차를 전이 장벽으로 부르지 않는다.

원자료 해시와73개 독립 수치 대조를 same_grip_modes_replay.json에 보존했다.
각도·에너지·곡률처럼 다른 단위의 오차는 항목별로 읽는다. 새 원자 평가0이다.

### 직선 보간의 원자 간격

원자 번호를 보존한 보간은 r_i(α)=(1-α)r_i^load+α r_i^return, 0≤α≤1이다.
α는 시간이나 변형률이 아니다. 모든64,620쌍에 대해 상대벡터 d0+αv의
거리 최소를 연속 구간에서 계산했다. v≠0이면 α*=clip(-d0·v/|v|²,0,1)이고,
v=0이면 거리는 일정하다. 여기서 clip은 기하학적 선분 투영이다.

최소거리는1.710907414 Å, α=0.493424705이며 자유원자253/286쌍이다.
해당 쌍의 양끝 거리는2.329662556/2.358467384 Å다. 두 끝점에서 짧지 않은
쌍이 직선 연결 중간에서 크게 압축되는 경로를 만들 수 있다는 뜻이다.
이 길이를 임의의 물리적 충돌/균열 판정값으로 사용하지 않는다.

20쌍의 독립 bounded scalar 최적화와 대조한 거리 오차는 최대4.44e-16 Å,
경로 역전 및 강체 회전·병진 대조는 최대7.11e-15 Å였다.257개 보간점의
최저거리는1.710912008 Å로 연속 최저거리보다 크다. 유한 표본의 극값과
연속 경로의 극값은 일반적으로 같지 않다. 차트는 시각검수 완료했다.

새 원자 에너지/힘 평가0, DFT0, MD0이다. 이는 기존 원자료의 새 기하 분석이다.

## 실제 장벽 계산 전의 순서

1. 같은 grip에서 두 끝점을 일관된 힘 정확도로 정밀화하고 허용 자유도의
   전체 곡률을 확인한다. 세 전체 Hessian과 축력조건 확장 감사는 완료했다.
   곡률은 양수지만 잔여 힘이 있으므로 정확한 정지점 정밀화는 별도 미완료다.
2. 위 압축을 줄이는 기하 초기 경로와 다른 초기 경로를 비교한다. 기하 보정
   목적함수는 실제 Si 에너지가 아니며 그 값의 높이를 장벽으로 쓰지 않는다.
3. 같은 재료 모델·경계에서 경로를 이완하고 image 수/최대 잔여 힘을 확인한다.
   직선 경로의 몇 점만 평가한 최대 에너지는 수렴한 안장점이나 장벽이 아니다.
4. 안장점의 정지성, 허용 공간에서 음의 곡률1개, 양방향 하강의 끝점을 검사한다.
   한 경로가 수렴해도 전역 최저 경로를 찾았다는 뜻은 아니다.
5. 도달한 상태가 새 균열인지 표면/내부 재구성인지 독립적으로 판정한다.
   실제 B가 정해지기 전의 경로는 '원자 재배열 경로'로 명명한다.
6. 열적 상태공간·commitment·좌표 축약·M을 검증해야 확률 및 물리시간으로 연결한다.

이번에 승인된6시간 작업 창에서 이 모든 항목이 끝났다고 가정하지 않는다. 현재 큐의
정적 곡률·Si/O 힘 감사·무축력 복귀·비선형 국소 검사와 미완료 경로 계산을
최종 보고서에서 구분한다. 기존 crack seed/K 경계/강체 분리를 개시로 바꾸지 않는다.
