# 두 모델 비교의 자료 범위와 후속 보완

## 학습 계보와 독립성

2026-09-28 확인한 제작사 자료는 MP-0b3의 학습 자료를 MPTrj, MPA-0를
MPTrj+sAlex로 명시한다. 두 모델은 MPTrj를 공유한다. 모델 두 개의 일치를
서로 독립인 재료 검증이나 보정된 예측 오차 범위로 해석할 수 없다는 것이
이번 연구의 판단이다. CP2K/QE 감사 구조와 사전학습 구조의 직접 중복은
아직 대조하지 못했으므로 완전히 분리된 시험 집합이라고 주장하지 않는다.
[공식 모델 설명](https://github.com/ACEsuit/mace-foundations),
[MPA-0 배포](https://github.com/ACEsuit/mace-foundations/releases/tag/mace_mpa_0),
[MP-0b3 배포](https://github.com/ACEsuit/mace-foundations/releases/tag/mace_mp_0b3).

CP2K 자료의 공개 저장소는 산화용 GAP와 그 학습 자료를 함께 배포한다.
따라서 해당 GAP를 같은 자료에 다시 평가하는 것도 독립 시험이 아니다.
이 진술은 이번 MACE 평가의 학습 중복이 확인되었다는 뜻은 아니다.
[자료 제작자 저장소](https://github.com/lukas-cvitkovich/MLFF-SiOx).

## 199개 표본의 범위

추론 러너와 별도 정수 인덱스 구현의 표본 선택이 정확히 일치함을 확인하고,
199개 입력 원자료의 해시를 후보 예측 전에 고정했다. 기존 CSV의 원자수 가중
힘 성분 RMSE를 재계산한 결과다. 새 MACE 평가나 DFT가 아니다.

|자료|전체 구조|선택 구조|전체 조성/선택 조성|전체 기존 RMSE|선택 기존 RMSE|
|---|---:|---:|---:|---:|---:|
|CP2K, N≤320|1013|135|14/14|0.372760|0.518244|
|QE|1159|64|30/20|0.691243|0.351422|

RMSE 단위는 eV/Å이다. 각 원자 힘의 세 성분을 같은 비중으로 계산했으며
프레임별 RMSE의 단순 평균이 아니다. 원자료 표와 선택 규약 해시는
`mpa_sampling_scope/summary.json`, 199개 입력 해시는 `source_raw_manifest.json`에 있다.

특히 QE의 Si-only 그룹은 전체471개에서1.273789, 선택16개에서는0.213559다.
이 그룹은 웨이퍼 하중 상태로 정의된 집합이 아니므로 전체 수치 역시 실제
웨이퍼 오차를 뜻하지 않는다. 다만64개 결과를1159개 전체 결과처럼 보고할
수 없다는 직접적인 증거다. 원자료 순서에서 균등 간격으로 고르는 방식은
무작위 표본이 아니며, 상관된 구조들을 독립 표본으로 세어 신뢰구간을 만들지 않는다.

## 보완 실행은 아직 대기 중

기존199개 후보 예측이 완료·재검증되면 그 예측을 보존한다. 새로운 보완
폴더에서 CP2K135개와 기존 QE64개를 재사용하고, QE의 나머지1095개를
추가한다. 후보 결과를 본 뒤 오차가 유리한 구조만 추가하는 방식이 아니라
기존 모델의 표본 범위 감사 후 QE 전체를 선택한 것이다.

완료하면 보완 폴더는1294개(CP2K135+QE1159)가 되지만 새 후보 예측은1095개다.
새 예측 중9개에서 표준 calculator와 대조하므로 계획된 새 forward는1104회다.
기존199개 재사용을 새 계산으로 중복 합산하지 않는다. 아직 실제 실행 횟수가 아니다.

`complete_mpa_qe_v13.py`는 부모 모델·선택 규약·좌표·원소·주기성·DFT/기존모델
원자료를 확인하며, 시간 종료와 부분 자료를 보존한다. 별도
`replay_mpa_qe_v13.py`는 부모와199개 예측 배열의 정확한 일치, 전체 행의
원자료·집계·동일 조성 에너지차·계산 횟수를 독립 대조하도록 준비했다.
구문·CLI 확인 후 NaN이 최대오차 집계에 가려지는 반례를 재현하고 새 재검증기를
보완했다. 비정상 스칼라/원자수/대조군 목록 검사 관련 합성 시험11개가 통과했다.
실제 후보 추론·원자료 재검증이 통과했다고 보고하지 않는다.

현재 원자 큐와 중복 실행하지 않는다. 큐가 끝나고 종료까지60분 이상 남았을
때에만 최대1200초 예산으로 시작한다. 미완료이면 부분 원자료와 이유를 남긴다.
전체 QE에서 좋아지더라도 Si 초기 균열 상태·경로·자유에너지·물리시간의
검증이 자동으로 끝나는 것은 아니다. Al/UI/생산 모델을 바꾸지 않는다.
