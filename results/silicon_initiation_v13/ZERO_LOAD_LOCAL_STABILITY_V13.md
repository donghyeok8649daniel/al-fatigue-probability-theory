# 외부 축력을 제거한 뒤 남은 배치의 국소 안정성

## 무엇을 검사했나

처음에 균열을 넣지 않은 360개 Si 원자의 유한 시편에서, 10%를 거쳐
8%로 복귀한 배치를 외부 축력 0으로 이완했다. 이완 자체는 앞선
return_zero_force에서 완료했다. 이번에는 그 저장 배치의 에너지 곡률을
독립적으로 검사했다. 같은 상태의 힘 수렴과 곡률 검사를 구분한다.

216개 자유 원자의 648개 Cartesian 좌표에 양쪽 강체 고정부의 대칭
축 방향 이동 좌표 u를 하나 더한다. 정규화는 u=6ΔL이며, ΔL은 두 고정부
사이 길이 변화다. 따라서 외력의 에너지는 G=U-Tu/6이다. 이번 T는 0이다.
측면 고정부 이동·회전·다른 표면 조건을 모두 허용한 문제가 아니다.

## 실제 완료 결과

- 649행 전체를 새로 자동미분했다. 새 모델 평가 49회, 새 AD649행이다.
  이 단계에서 재사용한 Hessian 행은 0개다.
- 최저 곡률 0.0150298619131 eV/Å², 음의 고유값 0개.
- 같은 위치의 고정부 고정 부분행렬도 음의 고유값 0개다.
- 잔여 축약 기울기 최대값 2.44831×10⁻⁶ eV/Å. 엄밀한 정지점으로
  가정하지 않는다. 계산된 양의 곡률은 이 근방의 선형 안정성을 지지한다.
- 독립 6방향의 힘·에너지 유한차분 검사를 완료했다. 작은 힘 차분 간격
  10⁻⁴ Å에서 Hessian 작용의 최대 노름 오차는 5.33338×10⁻⁹ eV/Å²다.
  에너지 차분의 최대 오차는 2.73570×10⁻⁶ eV/Å²다.
- 저장 행렬의 고유값을 다른 선형대수 경로로 다시 계산한 최대 차이는
  6.75016×10⁻¹⁴ eV/Å²다. 이 원자료 재검증의 새 모델 호출은 0회다.
- 실제 수치 계산 경과 시간 3104.2344초. 이것은 CPU 시간이나 물리적
  원자 운동 시간이 아니다. 실행 프로세스와 재검증 프로세스 모두 exit0.

## 길이 변화와의 관계

무축력 복귀 길이는 이전의 초기 무축력 길이보다 2.237173 Å, 즉
7.43611% 길고, 시편 전체 에너지는 8.150923 eV 높다. 이번 곡률 결과는
이 배치가 단지 힘 기준만 만족한 수치 정지 상태인지 살피는 근거를 보완한다.
두 상태 사이의 전이 경로나 장벽은 계산하지 않았다.

자유 원자가 선형으로 재조정되는 조건에서 축 방향 접선 강성은
dT/dΔL=2.33884623 eV/Å²이다. 현재 고정부 간 거리와 원래 단면적으로
환산한 유한 시편의 공칭 접선값은 63.58523 GPa다. 고정부·자유표면·현재
배치를 포함한 이 시편의 값이며 벌크 Si 영률이나 웨이퍼 실측값이 아니다.

잔여 기울기에 대한 국소 이차식 보정은 최대 원자 이동 3.39169×10⁻⁵ Å와
에너지 감소 5.64713×10⁻¹⁰ eV를 예측한다. 실제 추가 이완을 수행한 값이
아니며 이 선형 추정으로 원본 배치나 에너지를 덮어쓰지 않았다.

## 아직 확보하지 않은 것

양의 곡률로 첫 균열 상태 B, 유한온도 자유에너지, 개시 장벽 또는 유지
시간을 정할 수 없다. 단위 변환이나 이 길이 차이로 실제 소성·피로 수명을
만들지 않는다. 산화층과 도펀트가 없는 현재 시편의 결과를 도핑된 웨이퍼나
열산화 Si/SiO₂ 계면의 검증으로 부르지 않는다.
