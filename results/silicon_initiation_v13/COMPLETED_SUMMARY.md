# Si 첫 균열 개시 연구: 이번 계산의 완료 결과와 남은 물리 검증

## 핵심 판정

같은 변위에 놓인 서로 다른 원자 배치와 무하중 복귀 배치의 국소 곡률을
실제로 검사했고, 원자 에너지 후보의 공개 DFT 비교 범위를 넓혔다.
그러나 실제 Si의 첫 균열 상태 A/B, 유한온도 자유에너지, 이동도,
물리 시간과 개시 확률은 여전히 검증되지 않았다. 재료 모델 채택이나
생산 Si/Hz 활성화는 하지 않았다. 기존 Al/UI/생산 에너지와 v12 자료는 보존한다.

## 모델의 큰 틀

원자 에너지 U로부터 선택 좌표 q에 조건을 건 자유에너지 F(q)를 얻고,
그 위에서 확률밀도를 보존적으로 이동시킨다.

    ∂P/∂t = -∇q·J
    J = -M(q) [P∇qF + kBT∇qP]

M은 양의 기계적 이동도 행렬이다. 전자/정공 이동도와 다르다.
첫 균열을 나타내는 검증된 경계 B의 흡수 흐름을 적분해야 개시 확률이 된다.
Si의 실제 좌표·상태 B·F·M은 이번 정적 계산만으로 정해지지 않는다.
자세한 현재 원리와 경로 조건은 CURRENT_MODEL_AND_PATH_GATE_V13.md 참조.

## 실제 시편과 새 곡률 계산

시편은 360개 원자의 순수 Si 유한 프리즘이며 내부 균열을 미리 넣지 않았다.
216개 원자는 자유롭고 144개는 두 강체 고정부를 이룬다. 산화층·도펀트가
없는 이 시편을 실물 산화 웨이퍼나 도핑 웨이퍼로 부르지 않는다.

| 상태 | 자유도 | 최저 곡률 (eV/Å²) | 음의 고유값 | 새 평가 / 새 AD행 |
|---|---:|---:|---:|---:|
| 처음 8% | 648 | 0.02947002388 | 0 | 49 / 112 |
| 10% 후 복귀 8% | 648 | 0.02282159177 | 0 | 49 / 648 |
| 이완한 10% | 648 | 0.02172627600 | 0 | 49 / 648 |
| 재배열 뒤 무축력 복귀 | 649 | 0.01502986191 | 0 | 49 / 649 |

모든 행렬 뒤 독립 6방향의 힘·에너지 차분을 검사했다. 처음 8%는
기존 539행의 입력/모델/기저/기울기 해시와 3개 재계산 행을 확인하고
109행을 추가했다. 새 AD112에는 이 검증 3행이 포함된다.
8%·10% 상태의 힘 잔차는 최대 약 7×10⁻⁴ eV/Å이고, 무축력 복귀는
2.44831×10⁻⁶ eV/Å다. 정확한 정지점이나 전역 최소점으로 가정하지 않는다.

세 고정변위 상태에 축 방향 고정부 이동 좌표를 추가한 649차원 검사도
완료했다. 새 평가 27회/AD3행, 현재 648행 세 벌은 재사용했다. 각 상태의
반력에 맞춘 서로 다른 외력을 사용했다. 독립 52개 산술 대조를 통과했다.
새 force relaxation이나 모든 traction 경계조건의 검증은 아니다.
FIXED_AND_FORCE_ENSEMBLES_V13.md와 ZERO_LOAD_LOCAL_STABILITY_V13.md 참조.

## 같은 8%라도 상태와 변형 방향은 다르다

최초와 복귀 상태의 자유원자 RMS 위치 차이는 1.054057 Å이고,
복귀 상태의 에너지는 9.719223 eV 낮다. 가장 부드러운 방향의 각도는
19.95127°다. 최초의 최저 방향을 고정하면 곡률은 0.029470에서
0.097748 eV/Å²로 증가하므로 최저값 하나의 감소를 전체 연화로 읽지 않는다.
같은 방향·부분공간 비교의 독립 73개 대조를 통과했다.

처음 상태의 국소 이차식을 복귀 위치까지 외삽하면 +222.234825 eV를
예측해 실제 -9.719223 eV와 다르다. 두 상태를 잇는 단순 직선에서는
한 원자쌍 간격이 양끝 2.329663/2.358467 Å에서 중간 1.710907 Å로 줄어든다.
이는 경로 초기화와 국소 외삽의 한계이며 새 에너지 경로·안장점·장벽이 아니다.

## 무하중 복귀와 국소 조화 근사

외부 축력을 0으로 바꾸어 실제 147회 평가로 이완했다. 축력 잔차
2.65197×10⁻⁶ eV/Å, 자유원자 최대힘 3.32972×10⁻⁶ eV/Å로 사전 기준을
충족했다. 이전 초기 무축력 길이보다 2.237173 Å(7.43611%) 길고,
시편 전체 에너지는 8.150923 eV 높다. 이번 새 649차원 양의 곡률은
이 배치의 국소 안정성 근거를 보완한다. 실제 소성·균열·유한온도 유지
시간이나 두 무축력 상태 사이 장벽을 인증하지 않는다.

동일 고정부의 두 8% 상태를 고전적 단일 조화 우물로 가정하면,
300 K의 국소 이차식 ΔF=-9.456409 eV다. 실제 유한온도 표본 추출이 아니다.
후속 72개 비선형 점과 출발상태 대조 2개를 실제 계산했다. 2σ 변위의
선택 방향 에너지 오차가 작아도, 수직 힘 잔차 0.07743/0.07385 eV/Å는
선형 기울기 변화 노름보다 크다. 따라서 전체 조화 우물의 정당성은 미확보다.
독립 72점/36쌍 원자료 재검증을 통과했다. ZERO_LOAD_AND_NONLINEAR_SCOPE_V13.md 참조.

## 재료 에너지 후보의 오차

기존 MP-0b3와 MPA 후보를 같은 DFT 원자료에서 비교했다. 처음 CP2K135/QE64를
선정하고, 이어 QE의 남은1095개를 추가해 QE전체1159개를 검사했다.
최종1294기록은 CP2K135+QE1159이며, 두 실행의 기존199개는 정확히 재사용했다.
새 DFT나 모델 재학습을 한 것이 아니다.

| QE 자료군 | 구조 수 | MP-0b3 → MPA 힘 RMSE (eV/Å) | 구조별 개선 / 악화 / 동률 |
|---|---:|---:|---:|
| O만 포함 | 22 | 0.972753 → 0.681436 | 15 / 6 / 1 |
| SiO₂ | 493 | 0.158227 → 0.106350 | 196 / 297 / 0 |
| 순수 Si | 471 | 1.273789 → 0.315089 | 378 / 79 / 14 |
| 기타 Si/O | 173 | 0.342723 → 0.303339 | 117 / 56 / 0 |

SiO₂의 전체 성분 RMSE는 줄었지만 과반수 구조에서 구조별 오차는 증가했다.
초기 선택 SiO₂의 Si 원자만 보면 0.112741→0.117281로 악화한 반면,
전체 SiO₂의 Si 원자에서는 0.193093→0.125939로 개선했다. 표본과 집계가 다르다.
Si40O16의 동일조성 에너지차 RMSE는 0.011200→0.018963 eV/atom으로 악화했다.
두 모델은 MPTrj 학습 기반을 공유하며 합의가 독립 오차 보증은 아니다.
MPA_SELECTED_COMPARISON_V13.md, MPA_FULL_QE_COMPARISON_V13.md 참조.

## 실패·부분·구현 시험·시간

큰 산소 구조69개(320<N≤1200)는 원래 시도와1회재시도 모두 모델 할당 전
12GB 가용 메모리 기준에서 실패했다. 실제 평가0개/새호출0회이며 두 폴더를
보존했다. 재시도 직전 idle12.53GB와 라이브러리·입력 준비 뒤의 메모리는
서로 다르다. 기준을 낮추지 않았고 세 번째 시도는 하지 않는다.

이번 구현 시험은 서로 다른17+10+11=38개 통과다. 최초 setup 실패와
새 임시 디렉터리 재실행을 함께 기록했다. 기존63개 시험을 다시 실행하거나
이번 합계에 넣지 않았다. 원자료 산술 대조와 pytest를 섞지 않는다.

새 평가 총1756회, 새 AD2060행. 재사용100MPa649행·loading8원본539행과
grip확장1944행/MPA199개예측을 별도로 기록했다. 새 DFT0, 새 MD0.
execution_accounting.json이 요약·해시 결합을, execution_timeline.json이
실제 큐 이력을 보존한다. Loading8의 회수 불가 exit code는 unknown이다.
경과 시간을 연속 CPU 사용이나 물리적 궤적 시간으로 바꾸지 않는다.
