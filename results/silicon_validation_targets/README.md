# Si 연구의 대조 자료와 샘플링 점검

논문을 먼저 확보하되, 실제 측정한 사건이 무엇인지부터 고정한다. 재료 물성을
맞추는 자료, 파단 수명 자료, 첫 균열 개시 자료는 검증하는 대상이 다르다.
현재 확인한 자료에서 첫 형성 시간과 비회복 확인을 직접 검증할 데이터는
확보하지 못했다. 기존 자료의 역할과 접근 제한은 source_ledger.json에 기록했다.

## 먼저 확보할 자료

|자료|대조할 항목|현재 확보 수준과 제한|
|---|---|---|
|Bartók 외, Si 원자 에너지 자료|베셀 후보의 에너지·원자힘·여러 구조|기존 원자료와 예측을 사용한다. 정적 전자구조 자료는 열평형·전이율의 정답이 아니다. 기존 제외 세트도 이미 살펴본 자료다.|
|Jaakkola 외, 도핑·온도별 탄성|C11/C12/C44와 온도 변화|기존 표 전사와 출처가 있다. 전기적으로 추정한 캐리어 농도와 불순물 원자 농도를 동일시하지 않는다.|
|Noda 외, 과잉 전하의 이상강도|전자·정공의 정적 결합 영향|기존 보충 표 전사다. 실제 B/P/As/Sb 원자가 있는 구조의 실험도, 웨이퍼 파단강도도 아니다.|

|Muhlstein 외, 단결정 박막 피로|박막과 환경의 최종 수명 비교|기존 출처 목록을 연결했다. 이번에 전체 원문·그림을 새로 검수한 자료로 보고하지 않는다.|

위 목록이 곧 물리 검증의 통과를 뜻하지 않는다. 표와 그림이 있는 것, 원래
개별 관측값을 보유한 것, 같은 조건으로 독립 실험을 수행한 것은 각각 다르다.
기존 논문과 관측값을 이미 본 상태이므로 현재 목록 전체를 맹검 자료라고 부르지 않는다.

## 특히 주의할 두 대조군

[Chen 외의 도핑 웨이퍼 논문](https://pubs.aip.org/aip/jap/article/138/5/055703/3357407/Fracture-strength-of-Czochralski-silicon-wafers)은
ball-on-ring 단조 파단 자료다. 이전에 전사한 조건별 요약값을 유지하고,
저자가 제공할 수 있다고 밝힌 개별 관측값을 별도로 구해야 한다. 유의한 차이를
검출하지 못했다는 결과를 모든 조건에서 도핑 효과가 없다는 증명으로 확대하지 않는다.

[Ikehara·Tsuchiya의 결정방향별 피로 논문](https://www.nature.com/articles/micronano201627)은
현재 다섯 시편 종류의 116개 시험을 보고한다. 노치가 있는 시편이며, 노치와
미리 넣은 균열은 구분해야 한다. 초기 미세 결함의 부재까지 인증한 자료는 아니다. 주요 그림의
세로축은 변위각 진폭이므로 MPa로 바로 읽으면 안 된다. 응력으로 옮기려면 논문의
FEM 변환을 대조해야 한다. 가로축은 최종 파단까지의 반복 수이며 램프 시험에는
상수 진폭 등가 반복 수가 쓰인다. 다른 패널에 반복 표시된 기준 곡선을 새 표본으로
세지 않는다. 논문의 균열 성장식과 성장 지수를 우리 개시 법칙으로 가져오지 않는다.

## 개시·비회복의 정답 자료에 필요한 것

- 최초 균열을 검출한 방법, 관측 간격, 공간 분해능과 초기 결함 상태.
- 최초 형성 시점과 파단 시점의 분리. 관측 사이에 생겼다면 시간 구간을 보존한다.
- 닫힘과 응집 회복을 구분할 관측, 복귀 하중과 확인 구간.
- 미파손 종료와 미확인을 그대로 기록한 개별 이력. 이를 임의 파단 시점으로 바꾸지 않는다.
- 같은 시편의 하중 파형·평균·진폭·응력비·주파수와 온도·습도·산소 조건.
- 결정면·하중 방향·단면·표면 가공·산화층·도핑 종류와 농도 측정 방식.
- 원래 측정한 힘/변위와 국소 응력으로 변환하는 방법, 배치·시편 식별자와 오차.

현재 찾은 최종 파단 수명 곡선으로 비회복 개시 시간을 적합하지 않는다.
후속 보정 전에 어떤 조건을 학습에 쓰고 어떤 조건을 끝까지 제외할지 정한다.
요약 통계, 그림에서 읽은 값, 실제 개별 관측값은 서로 바꾸어 부르지 않는다.
이 조사에서는 저자에게 메시지를 보내거나 자료를 요청하지 않았다.

확보 순서는 다음과 같다. 먼저 기존 원자 에너지·힘과 탄성 표를 기준으로 베셀
후보의 오차를 줄인다. 그다음 웨이퍼의 개별 파단 관측값과 피로 시험 이력·응력
변환 자료를 구해 조건이 같은 비교를 준비한다. 개시를 검증할 자료에는 시험 중
균열 관측과 하중 복귀 후 응집 회복 확인이 함께 있어야 한다. 그런 자료가 없으면
우리 실험에서 별도로 측정해야 한다. 최종 파단 시점을 최초 개시 시점으로 대체하지 않는다.

## 기존 열 샘플링에서 막힌 부분

이 부분은 기존 130회 MACE 에너지·힘 평가의 저장 자료를 새로 분석한 것이다.
새 원자 에너지 호출, DFT, MD, 물성 재적합은 모두 0회다.

|항목|처음 8% 출발|복귀 8% 출발|
|---|---:|---:|
|영역 밖 제안|0|0|
|예열 수용률|81.25%|75.00%|
|저장 전반 수용률|37.50%|50.00%|
|저장 후반 수용률|33.33%|25.00%|
|저장 후반 제안의 원자별 변위 RMS 평균 (Å)|0.08688|0.08508|
|후반 비선형 보정 변화의 중앙값 (무차원)|2.71991|2.66224|

128개 제안의 난수와 수용·거절을 다시 확인했다. 두 경우 모두 영역 밖 제안이
없었으므로 이 기록의 정체를 계산 상자의 벽 탓으로 설명할 수 없다.
648개 자유 좌표를 동시에 움직이는 제안이 실제 비선형 에너지로 보정되며,
예열과 후반의 수용 양상이 달랐다. 짧은 이력만으로 구체적인 장벽 높이 또는
어떤 제안 방법이 최선인지 판정하지 않는다.

다음 제안 이동을 검증하기 위해 실제 Cartesian 힘을 Gaussian 좌표의 보정
기울기로 옮기는 연구 함수를 추가했다. U는 총에너지, B는 고정 직교기저,
H=L L^T, r=r0+B(mu+sqrt(kBT)L^-T u)일 때 다음 식이다.

    Phi(u) = (U(r(u))-Uref)/kBT - u.u/2
    grad_u Phi = -L^-1 B^T F_cartesian/sqrt(kBT) - u

힘을 원자 수로 나누거나 크기를 잘라 맞추지 않는다. 고정 그립 행은 B에서
0이므로 반력이 기울기에 들어가지 않는다. 회전된 결합 좌표, 비선형 에너지의
독립 차분, 여러 온도, 정확한 조화 대조와 입력 오류 검사를 포함해 새 검사 5개와
기존 관련 검사 52개, 합계 57개가 통과했다. 실제 원자 HMC 샘플링은 이번에
수행하지 않았으며 기존 전체 회귀를 다시 실행했다고 보고하지 않는다.

이 기울기는 샘플링을 위한 것이다. 원자의 물리 운동량·이동도·시간 또는
균열 전이율이 아니다. 실제 Si 열평형, 개시 집합과 비회복 확인 구간은 여전히
미확보다. 논문을 추가로 찾은 것과 이 물리적 공백을 해결한 것을 구분한다.

## 재현

저장소 루트에서 NumPy/SciPy/pytest 환경을 사용한다. 새 출력 경로를 지정한다.

```powershell
python -m pytest solver_v1/test_silicon_sampling_score.py solver_v1/test_silicon_crack_records.py solver_v1/test_silicon_thermal_identity.py solver_v1/test_silicon_initiation_probability.py solver_v1/test_silicon_thermal_validity.py solver_v1/test_silicon_device_ensemble.py solver_v1/test_silicon_thermal_research.py -q -p no:cacheprovider
python -m results.silicon_wafer_feasibility.audit_sampling_obstruction --root . --output NEW_ANALYSIS
python -m results.silicon_wafer_feasibility.catalog_validation_sources --root . --output NEW_SOURCE_LEDGER
```

source_ledger.json의 DOI와 기존 숫자 파일·출처의 SHA를 따라 확인한다. 새로 원문을
읽거나 원자료를 확보하면 기존 조사본을 덮어쓰지 않고 접근 상태를 새로 기록한다.
원래 자료 요청·그림 수치화·실제 원자 계산은 위 명령에 포함되지 않는다.
