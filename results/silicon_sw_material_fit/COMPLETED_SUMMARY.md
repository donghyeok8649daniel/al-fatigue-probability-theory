# 실리콘 원자 에너지의 베셀 표현과 물성 보정

이번 작업은 순수 Si의 SW 에너지를 베셀 합으로 계산하는 기존 구현을 유지하면서
벌크 탄성과 표면·결함의 물성 오차를 줄이는 연구다. 생산 확률 솔버에 새 후보를
채택한 작업은 아니다. 알루미늄, UI, 생산 에너지와 물리 Hz 설정은 바꾸지 않았다.

## 현재 결과

원래 SW의 결합각 항에 `x²(1-βx)²`, `x=cosθ-c0` 형상을 도입하고,
선호각·거리 형상과 세 양의 진폭을 함께 검사했다. 모든 이웃 환경을 합한 뒤
중심 원자마다 에너지를 계산하며, 자기항과 비영 벌크 배경을 빠뜨리지 않았다.
각도 4차 항은 고정 텐서 성분과 J0–J4 베셀 적분으로 계산한다.

마지막 선택은 `final_selection.json`에 잠갔다. 양의 각도 경계의 30개 프로파일 중
12개가 선언한 조건을 통과했다. 같은 학습·완전 결정 E(V) 손실로 선택한 값은
93.9730677343이다. 손실에서 제외한 구조나 외부 검증 오차로 재선택하지 않았다.
다른 형상이나 전역 최적성을 인증한 결과는 아니다.

- 거리 형상: σ=1.75 Å, γ=1.5, 고정 물리 cutoff=3.77118 Å.
- 선호각: c0=-0.37357245686009144, β=0.3640142880725576.
- 세 진폭: 1.5154459672870815, 0.8032941483520551, 1.7423070209244775.
- 평형 격자: 5.4610215037046075 Å.
- C11/C12/C44 기준: 153.28991/56.25009/72.17693 GPa.

격자와 세 탄성 기준, 원래 SW보다 벌크 상대 에너지 오차를 키우지 않는 조건을
동시에 만족했다. 탄성 기준은 공개된 유한 변형 응력 적합값이다.
독립 인증된 정확한 DFT 0변형 Hessian과 동일하다고 가정하지 않았다.

| 오차 | 원래 SW | 현재 후보 |
|---|---:|---:|
| 벌크 힘 RMSE (eV/Å) | 0.17690 | 0.20863 |
| 벌크 상대 에너지 RMSE (eV/원자) | 0.02881 | 0.02534 |
| Si(111) 힘 RMSE (eV/Å) | 1.04073 | 1.02104 |
| Si(111) 상대 에너지 RMSE (eV/원자) | 0.21937 | 0.17002 |

Si(111) 힘 오차는 약 1.9%, 상대 에너지 오차는 약 22.5% 줄었다.
벌크 힘은 악화했고, 선택 후 외부 검사에서도 입계·비정질·적층결함은 악화했다.
두 침입형 원자 결함은 개선됐다. 이 외부 자료는 앞선 후보에 이미 검사한 세트로,
완전히 새로 확보한 검증 자료는 아니다. 현재 후보를 재료 모델로 채택하지 않았다.

## 추가 검증

- 공개 조화 진동수 대비 RMSE는 1.68949 THz, 최대 차이는 3.39967 THz다.
  Γ 광학 모드는 17.25580 THz, 참조는 15.08471 THz다.
  9³ 파수 표본의 최소 고유값은 수치 바닥 안에 있었으나 전체 파수 안정성 인증은 아니다.
  저장된 내부 상대 변위 Hessian을 원자 두 개의 환산질량 m/2로 재생한
  Γ 광학 모드는 기록한 값과 일치했다. 같은 Si 질량 28.0855 amu 아래에서
  내부 곡률은 문헌 진동수로부터 환산한 값보다 약 30.9% 크다.
  전단의 고정 내부 곡률 103.92614 GPa에서 내부 이완 감소 31.74921 GPa를
  빼면 C44=72.17693 GPa다. 이완 탄성 일치와 광학 곡률 일치를 구별한다.
  문헌 값의 환산은 새 DFT Hessian 계산이 아니다.
  양의 각도 경계 30개 형상의 저장된 내부 곡률을 모두 대조했다.
  조건을 통과한 12개는 Γ 광학 모드가 17.17867–17.32321 THz로,
  문헌의 15.08471 THz와 모두 차이가 남았다. 선택은 바꾸지 않았다.
  이 유한 후보군의 대조이며 전체 밴드 재계산이나 계열 불가능성 증명은 아니다.
- 내부 원자힘을 이완한 응력-변형률 대조에서 0.1% 간격의 탄성은
  153.289487/56.252369/72.175857 GPa였다. 간격 감소에 따라 접선값에 접근했다.
- 강체 shuffle/glide 계면의 첫 국소 안정성 상실 하중은 37.388645/66.394614 GPa다.
  강체 분리 일은 2.872/8.637 J/m²다. 미리 균열을 넣지는 않았지만,
  지정 평면의 강체 분리 경로이므로 실제 시편의 첫 균열 개시로 부르지 않는다.
- 최종 후보의 4개 상태에서 5개 해상도를 비교한 베셀 20회·직접합 4회 검사가
  723.18초에 완료됐다. 가장 세밀한 Hessian 차이는 최대 2.1523e-8 eV/Å²였다.
  오차가 완전히 단조롭지는 않으며 보편 꼬리 오차 상한을 인증하지 않았다.
- 선택 후 고정된 세 힘 기저에서 Si(111) 힘만 적합하면 0.48907 eV/Å까지 낮아진다.
  이 계수는 탄성·에너지 조건을 풀고 얻은 진단값이다. 재료 적합으로 사용하지 않았다.
  저장된 벌크 행렬의 독립 대조에서 이 계수는 기준 격자에 -1.50128 GPa의
  법선 응력을 남겼다. 세 진폭에 대한 평형·두 법선 곡률 행렬은 rank 3이고
  condition number는 2.6453이다. 고정 형상에서 이 세 정확 조건을 지키는
  진폭은 잠근 값으로 정해진다. 다른 형상이나 전체 에너지 계열의 불가능성 증명은 아니다.
  이 검사는 원자료 행렬만 재생했으며 새 원자 계산·선택은 하지 않았다.

## 자료와 시험

기존 공개 DFT 원자료 2,475개 구조, 171,815개 원자를 사용했다.
PW91 벌크·(001)·(110)의 511개만 학습했고 1,964개는 손실에서 제외했다.
새 DFT, 새 MD 또는 새 LAMMPS 실행은 하지 않았다.
자료의 PW91/PBE/미상 정보를 분리하고 열적으로 변형된 PW91 프레임을
상대 에너지의 고정 기준으로 사용했다. 응집 에너지 기준으로 해석하지 않았다.

원자료 564개 파일과 당시 소스 연결 233개를 검사했다.
12개 후보의 원자별 예측, 420개 구조군 오차, 264개 Gram 적합 손실을 독립 재집계했다.
기존 독립 LAMMPS 예측의 SW 복원 오차는 힘 3.55e-13 eV/Å,
에너지 1.52e-11 eV 이내였다.

실제 Git index blob을 새 트리에 복원한 뒤 33개 시험을 실행했다.
269.94초에 모두 통과했고, 실패·건너뛴 시험은 없었다.
ASE/NumPy의 알려진 형태 변경 경고 4개가 있었다.
별도 실행한 기존 회귀 24개도 통과했다.
시험 통과를 물성 채택이나 균열 개시 검증으로 읽지 않는다.

계산 도중의 실패, 잘못된 중간 결과, 원래 소스도 보존했다.
E(V) 정규화 및 재사용 오류, 계면 응력 표시의 10배 단위 오류,
JSON 저장 실패의 복구 기록을 교정 결과와 구별했다.
복구할 수 없는 과거 계산의 실행 시간은 미상으로 남겼다.

## 아직 확보하지 못한 것

실제 초기 시편의 개시 상태 A/B와 전이 경로, 집단좌표 자유에너지 F(q,T),
이동도와 기억효과 검증, 물리 시간, 첫 개시 확률과 피로수명은 미확보다.
이번 적합에는 도핑, 산화층, 수분과 잔류응력의 재료 보정이 없다.
고체의 열적 요동을 다룰 수 있지만 정적 에너지에 kBT를 넣는 것만으로
선택한 집단좌표의 동역학이 검증되지는 않는다.
집단좌표 에너지를 원자당으로 환산할 때는 열항과 이동도도 같은 확률법칙으로 환산해야 한다.

처음 보는 독자를 위한 설명과 수치는 `silicon_wafer_material_report.pdf`에 정리했다.
10쪽 전체의 수식·한글·표·그래프를 렌더링해 확인했고 `report_qa.json`에 해시를 남겼다.
재현 순서는 `README.md`, 원자료 검증은 `verify_material_package.py`를 따른다.
각 파일의 Git 바이트 해시는 `package_manifest.json`으로 확인한다.
