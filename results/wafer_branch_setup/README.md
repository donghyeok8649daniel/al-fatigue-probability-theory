2026-09-20 · `silicon-wafer-research` · 기준 `5f878370`

기존 Si 코드·원시 계산 결과와 필요한 공통 UI를 별도 작업 폴더에 옮긴 뒤
새 위치에서 회귀를 실행했다. 이 단계에서 물리 계산이나 적합을 새로 수행하지 않았다.

처음 전체 솔버 실행은 새 작업 폴더에 Al99 참조 파일이 없어 773 PASS,
18 FAIL, 28 ERROR, 8 SKIP으로 끝났다. 각 실패 원인이 같은 파일 누락임을 확인한 뒤
기존 참조의 SHA-256을 검사해 새 `.cache`에 준비하고 해당 **54개만 재실행하여 모두 통과**했다.
수집한 각 테스트와 결과를 대조해 최종 827개의 통과를 확인했다. 기준이나 구현을 바꾸지 않았다.
처음 orchestration의 exit 1도 원래 기록으로 남겼다.

새 checkout에서 전체 Al 회귀도 실행하려면 먼저 다음 명령으로 참조를 준비한다.

공통 UI 커밋은 `cc2e11d`, Si 연구 커밋은 `ff890ce`다. 기존 Al 작업 폴더의
변경 파일 221개는 이관 전후 동일함을 확인했고, 원래 브랜치는 진행시키지 않았다.
원래 인계 문서에는 게시 후 새 작업 위치만 안내한다.

연구 기록 안의 과거 HEAD/폴더/검증 시각은 계산 당시의 이력으로 보존했다.
공통 메시 검증 문서의 링크만 이 브랜치에 맞게 바꿨다. `.gitattributes`는
hash-bound Si 소스의 LF를 고정한다. 원본 매개변수와 자동 생성 SVG의 기존 공백은
네 파일에 한정한 whitespace 예외로 보존하며 코드의 공백 검사는 유지한다.

**정적 구현 검증과 재료·PMF·이동도·실제 수명 보정은 별개다.**
Si 생산 실행과 물리 Hz는 계속 비활성이다.
