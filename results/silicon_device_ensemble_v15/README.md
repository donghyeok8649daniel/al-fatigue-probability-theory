# Si 열분포·시험기 구속 연결 연구 v15

2026-10-01 KST. 출발점: Si 브랜치 `b02cb65`의 v14. 이번 요청은 Si 연구를
계속하면서 사용자가 설계 중인 피로시험기 CAD를 실험 준비에 반영하는 것이다.

## 결론

**강하게 구속된 고체에서도 kBT를 임의로 낮출 이유는 없다. 구속과 하중 장치가
에너지·허용 자유도·변위 분산을 바꾼다.** 이번에는 저장된 Si Hessian에 유한한
장비 강성을 연결한 식을 구현하고 독립적으로 검산했다. 실제 비선형 Si 열평형
샘플링은 메모리 시작 기준 미달로 실행 전 중단됐다. 현재도 Si의 실제 자유에너지,
이동도, 균열 개시 확률 및 물리 초/Hz 보정은 확보되지 않았다.

45개의 독립 물리 실험이라고 세지 않는다.

## 1. 시험기가 들어간 에너지

시편의 그립 간 상대 연장을 Δ, 액추에이터 설정 위치를 X, 장비의 등가 축강성을
K_m이라고 하자. 준정적 선형 탄성 장비를 가정하면

```text
Π(R_free, Δ; X) = U_Si(R_free, Δ) + (K_m/2) (X − Δ)^2
F_machine = K_m (X − Δ)
```

이 식은 같은 온도에서의 수동 탄성 장비 근사다. 모터 제어 지연, 관성, 마찰,
백래시, 전자 제어 잡음은 아직 포함하지 않는다. 실제 서보 제어기의 잡음을 열적
kBT라고 간주하지 않는다. 측정된 장비 강성은 현재 없다.

이상적인 힘 제어는 `Π = U − F_ext Δ`, 이상적인 그립 변위 고정은 `Δ = X`이다.
인장 dead-load 에너지로 무한 영역의 전역 평형이 존재한다고 가정하지 않는다.
이번 힘 제어 수치는 양의 Hessian 주변 **국소 조화 근사**다.

같은 정지점에서 허용 좌표 x에 대한 Hessian을 H, `Δ = vᵀx`라 하면

```text
H_device = H + K_m v vᵀ
C_classical = kBT H_device^(-1)
k_specimen = 1 / (vᵀ H^(-1) v)
Var(Δ) = kBT / (k_specimen + K_m)
dΔ/dX = K_m / (k_specimen + K_m)
```

따라서 장비가 단단할수록 그립 간 거리의 열분산은 작아진다. 완전 고정에서는
Δ의 분산이 0이지만 내부 원자 전체의 열운동이 사라지는 것은 아니다. 물리 온도와
kBT는 유지된다. 강한 원자 상호작용은 이미 H의 대각·비대각 성분에 들어간다.

v13 자료의 마지막 좌표는 실제 연장이 아니라 정규화된 그립 좌표 `c = 6 Δ`다.
이번 계산은 `v_last = 1/6`을 사용한다. 이 6을 빠뜨리면 강성과 분산의 환산에
36배 오류가 생긴다. N/mm 환산에서도 `1 eV/Å² = 0.01602176634 N/mm`를 사용했다.

## 2. 실제 저장 원자료에 적용한 결과

입력: `silicon_initiation_v13/dense_return_zero/raw_hessian.npz`.
360개 무산화·무도핑 Si 원자, 자유 원자 216개와 강체 그립 연장 1개로 649좌표다.
복귀 후 무축력 상태이며, 실제 CAD의 Al 시편과는 다른 나노 시편이다.

- 내부 원자 이완을 포함한 시편 강성: **2.33884623085 eV/Å²**.
- 직접 역행렬과 내부 원자 제거(Schur complement)의 상대차: **2.66e-15**.
- 300 K 무축력 국소 조화 연장 분산: **0.01105331314 Å²**.
- 아래 K_m 값은 민감도 검사용 가정이며 실제 시험기의 측정치가 아니다.

| K_m / k_specimen | Var(Δ) / Var(Δ)_힘제어 | dΔ/dX |
|---:|---:|---:|
| 0 | 1 | 0 |
| 0.01 | 0.990099 | 0.009901 |
| 0.1 | 0.909091 | 0.090909 |
| 1 | 0.5 | 0.5 |
| 10 | 0.090909 | 0.909091 |
| 100 | 0.009901 | 0.990099 |
| 무한대 | 0 | 1 |

이는 단일 정지점의 **고전 조화 근사**다. v14에서 확인한 비조화성과 양자 민감도는
해결되지 않았다. 649번째 장비 좌표의 관성도 정의하지 않았으므로 이 결과로
장비 결합 양자 진동수나 시간 척도를 계산하지 않았다. 이 나노 시편의 강성을
거시 시험기·Al 시편으로 그대로 옮기지 않는다.

## 3. 비선형 열분포: 구현한 것과 아직 못 한 것

v14의 Gaussian 제안은 실제 MP-0b3 열분포와의 가중치 차이가 컸다. 따라서
Hessian은 제안 분포를 만드는 데만 쓰고, 수용·거절에는 실제 비선형 U를 넣는
기존 pCN 샘플러에 현재 360원자 형상을 연결했다.

```text
r(u) = r_source + B [−H^(-1)g + sqrt(kBT) L^(-T) u],  H = L Lᵀ
Φ(u) = [U(r(u)) − U_source] / kBT − |u|²/2
u_proposed = sqrt(1−β²) u + β z,  z ~ Normal(0,I)
acceptance = min(1, exp[Φ(u) − Φ(u_proposed)])
```

일정한 좌표 변환 Jacobian은 한 chain의 수용 비에서 상쇄된다. 두 chain의
제안 중심/Hessian은 달라도 실제 에너지와 Cartesian 허용 영역은 같다.
pCN의 Gaussian 기준 측도 보존을 이용한 방법이다.
[Cotter et al., Statistical Science 2013, DOI 10.1214/13-STS421](https://arxiv.org/abs/1202.0709).

프로토콜은 최초/복귀 8% 두 상태, 300 K, 독립 난수 seed 151/953, β=0.35,
chain당 준비 16제안+저장 48제안이다. 두 초기 재평가를 합쳐 최대 모델 호출
130회를 계획했다. 거절 상태도 반복해서 기록하며 MC 제안 번호는 시간이 아니다.
이 표본화는 자유에너지 수치 적분을 준비하는 연구이며, 결정론적 확률밀도 PDE를
Monte Carlo 균열 횟수로 대체하는 것이 아니다.

유한 영역은 두 기준 구조의 중간 위치에서 자유 원자의 각 Cartesian 성분 ±3 Å,
모든 원자쌍 거리 1 Å 이상이다. 영역 밖은 거절하며 좌표를 잘라 넣지 않는다.
이 영역은 계산용이며 intact A 또는 cracked B의 정의가 아니다. 영역 크기 의존성과
chain 혼합은 아직 검증하지 않았다. 실행이 끝나도 48점만으로 평형을 인증하지 않는다.

**이번 실행은 모델 할당 전 중단됐다.** 입력·모델 SHA와 초기 영역 검사는 완료했지만
새 에너지/힘 평가, chain 표본, 혼합 검사, 자유에너지 추정은 모두 0/미완료다.
`nonlinear_pilot/summary.json`과 `allocation_check.json`에 실패를 보존했다.
기존 메모리 기준을 낮추거나 사용자 프로그램을 종료하지 않았다.

## 4. 확인한 피로시험기와 실험 데이터 연결

바탕화면 파일의 실제 design을 읽었다. 내장 prompt는 설계 당시 요구 사항으로
취급했고 추가 CAD 작업 지시로 실행하지 않았다. CAD와 다른 저장소는 수정하지 않았다.

- 2주식 수직 전동 시험기, 상부 로드셀·그립, 하부 이동 크로스헤드·그립.
- 모터·커플링·볼스크루·가이드·변위센서·리미트센서·보호 구조 포함.
- Al 시편: 전체 길이 100 mm, 평행부 30 mm/Ø8 mm, 물림부 Ø16 mm,
  전이부 각각 15 mm. 파일에는 시편의 추가 가공 피처가 없다.
- 이동 크로스헤드의 임시 조립 범위 z=385~395 mm는 **장비 정격 스트로크가 아니다**.
- 최대 하중, 주파수, 장비 강성, 독립 시편 변형률 센서, 첫 균열 검출 방법은 미확정.
- 이 파일의 조립 관계·외형만으로 접촉, 체결력, 하중 전달, 제어 성능을 검증하지 않았다.

기본 평행부 단면적은 **50.26548246 mm²**다.

```text
σ_nominal [MPa] = F_measured [N] / 50.26548246 [mm²]
1 kN → 19.89436789 MPa
100 MPa → 필요한 축력 5.026548246 kN
```

100 MPa에서 E=70 GPa를 **예시로 가정**하면 평행부 30 mm의 탄성 연장은
0.042857 mm다. 이 값을 모터·크로스헤드 왕복거리와 동일시하면 안 된다.
실제 이동량에는 시편 전이부/물림부, 그립·프레임·로드셀·구동계 변형과 미끄럼이
포함될 수 있다. E=70 GPa는 이번에 측정/보정한 값이 아니다.

별도 [AI_CAD_Stuff 저장소](https://github.com/donghyeok8649daniel/AI_CAD_Stuff/tree/6a81c64c08bce6f74e2723278fc8efecd9b03a37)의
최신 HEAD `6a81c64`를 별도 읽기용 캐시에서 확인했다. 기존 로컬 checkout은
`c3ae90c`로 오래되어 연구 근거로 최신이라고 부르지 않았다. 최신 버전은 이미
다음 CSV 채널을 제공하므로 별도 중복 양식을 만들지 않는다.

```text
time_s, cycle_index, force_N, crosshead_displacement_mm,
gauge_strain, temperature_C, source, quality_flag
```

이 양식에 맞춰 **실제 힘**, **독립 시편 변형률**, **물리 시간**, **온도**를 보존한다.
현재는 빈 양식만 있으며 실험 데이터가 아니다. 실제 Hz가 들어와도 연구 PDE의
물리 시간 gate는 자동으로 열리지 않는다. 힘 진폭의 동적 검증은 정적 로드셀
검사와도 구별해야 한다. [ISO 4965-1 공식 범위 설명](https://committee.iso.org/standard/50238.html?browse=ics).
이는 표준 전문을 적용해 이 설계를 인증했다는 뜻이 아니다.

## 5. 첫 균열 개시를 실험과 연결하기 위한 조건

연구상 첫 도달 시간은 `τ_B = inf{t : R(t) ∈ B}`지만, 현재 Si에 대해 물리적으로
검증된 cracked 집합 B가 없다. 단일 결합의 일시적인 신장, 표면 재배열,
전하중 후 다른 에너지 최소로의 이동을 곧바로 첫 균열이라고 세지 않는다.

시험기에서는 균열 영상/표면 관찰 등 **검출 방법·최소 분해능·관찰 간격**을 정하고,
첫 검출 시각을 마지막 미검출~첫 검출 사이 구간으로 보존해야 한다. 파단 사이클이나
로드셀 신호 변화만으로 원자 규모 첫 균열 시각을 확정하지 않는다. 검출까지 성장한
시간을 개시 시간과 혼합하지 않는 것이 목적이다. 검출 문턱은 보편적 원자 균열
길이를 만들어 넣는 방식으로 정하지 않는다.

실리콘 웨이퍼 시험까지 확장할 경우에는 별도 치구·두께·결정 방향·표면/에지 상태,
산화층·도펀트·농도·온도/습도 정보를 추가해야 한다. 현재 Al 원통 그립을 검증된
Si 웨이퍼 치구로 간주하지 않는다. 지금의 원자 계산에는 산화층과 도핑이 없다.

## 6. 남은 작업 및 재현

1. 가용 메모리가 기존 기준을 충족할 때 **새 출력 폴더**에서 비선형 파일럿 실행.
   기존 중단 기록을 덮어쓰지 않는다. 이번에는 자동 재시도/예약 실행을 만들지 않았다.
2. 모든 제안·실제 에너지·난수·수용 여부를 독립 재검산. 평형·혼합·영역 크기
   검증을 통과하기 전에는 free energy/개시 확률을 산출하지 않는다.
3. 측정된 힘과 독립 변형률로 시편 및 장비 compliance를 분리한다. 장비가 확정되면
   주파수별 반응, 정렬/굽힘, 그립 미끄럼, 첫 균열 검출 이력을 실험 근거로 추가한다.
4. 도핑/산화 실제 Si 에너지 검증, 물리 A/B, 이동도/기억효과 연구는 계속 미완료다.

원격 CAD 소스 식별자는 `CAD_REPOSITORY_REFERENCE.json`에 있다.
