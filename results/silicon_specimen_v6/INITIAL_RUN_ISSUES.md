# 최초 실행 기록의 제한

최초 `specimen_bridge.json`은 실제 18회 이완의 수치·종료 상태를 보존한다.
그러나 저장 경로에 `Path.with_suffix('.npz')`를 적용하면서 소수점 하중
`K0.8`은 `K0.npz`, `K1.2`는 `K1.npz`가 됐다. 후자는 같은 반경의 `K1`
상태를 덮어썼다. 따라서 **최초 18개 상태 배열이 모두 보존됐다고 주장하지
않는다**. 소수점 경로 회귀 검사를 추가하고 전체 18회를 새 디렉터리에서
다시 실행한다. 새 실행만 최종 원자 배열 검증의 기준으로 사용한다.

최초 `internal_boundary`는 SW 11개 조건을 완료하고, 원래 Tersoff 파일명을
읽을 때 FileNotFoundError로 중단됐다. 해당 checkpoint와 배열·소스를 보존한다.
새 전체 실행은 별도 폴더에서 수행하고 실제 완료 상태를 최종 보고서에 기록한다.

최초 후처리의 Tersoff 거리 cutoff 3.2 Å 표기도 잘못됐다. 공식 Si-Si-Si 항의
R+D=2.85+0.15=3.0 Å를 파일에서 직접 읽도록 수정했다. 이는 기하학적
분류에만 쓰였으며 LAMMPS의 원자 에너지·힘은 처음부터 원본 매개변수 파일을
사용했다. 새 실행에서는 올바른 cutoff로 원시 거리와 분류를 함께 저장한다.

최초 specimen 모듈 docstring의 문헌 DOI 오기는 BF00186854로 수정했다.
`source_snapshots/*_initial.py`는 이 수정 전의 실제 실행 소스/hash를 보존하는
역사 기록이며, 현재 재현 코드나 올바른 문헌 식별자를 대신하지 않는다.
