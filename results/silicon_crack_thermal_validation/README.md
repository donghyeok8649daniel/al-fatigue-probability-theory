# Si 첫 균열과 열항 검증

2026-10-05. 초기 내부 균열을 넣지 않은 Si 시편을 연구한다. 첫 균열 형성과
그 뒤 회복되지 않는 개시를 함께 기록하며, 후자를 주 결과로 삼는다.

## 현재 결론

열항의 정규화와 새 이력 집계는 독립 수학 검사를 통과했다. 실제 비선형 Si
에너지로 두 초기 상태의 짧은 열분포 샘플링도 완료했다. 그러나 두 체인이
서로 다른 초기 상태 근처에 남았고, 열적 항등식의 잔차가 남았다. 실제 열평형은
검증되지 않았다. kBT를 낮춰 맞추거나 자유에너지·균열 확률·수명을 채택하지 않는다.
공간 구조에서는 국소 원자 재배열이 확인됐지만 첫 균열 판정은 미완료다.

## 함께 정한 첫 균열 기준

원래 연결된 재료의 국소 영역에서 응집 결합의 상실이 서로 마주 보는 새 분리면과
그 경계를 만드는 사건을 균열 형성으로 본다. 원자 간 거리, 이웃 수, 응력 최대값,
시편 전체의 단절은 각각 단독으로 이 사건을 정의하지 못한다.

- 최초 형성: 새 균열이 처음 나타나는 사건. 이후 회복 여부는 따로 기록한다.
- 비회복 개시: 명시한 하중·온도·환경과 확인 구간에서 응집 연결이 회복되지
  않은 사건. 연구의 주 결과다.

유한한 계산으로 영원히 재결합하지 않는다고 주장하지 않는다. 균열면의 접촉과
응집 결합의 회복도 구분한다. 회복은 분리 영역을 가로지르는 연결과 작은 개방·전단
변형에 대한 하중 전달 응답이 적절한 건전 기준으로 돌아왔는지를 확인한다.
원자들이 최초의 정확한 위치로 돌아와야 한다는 뜻이 아니다. 부분 회복 또는
확인 시간이 부족한 상태는 미판정으로 남긴다.

후보가 처음 형성된 시점과 비회복을 확인한 시점도 따로 남긴다. 주 사건의
확률은 해당 시점까지 확인된 사건을 센다. 나중에 확인한 결과를 과거 시점에
미리 알았던 것처럼 생성자에 넣지 않는다. 복귀 하중과 유지 구간은 실제
시험 조건 및 회복 시간 연구를 바탕으로 정해야 한다.

작더라도 회복되지 않고 남은 균열은 개시로 기록한다. 이후 크기 증가는 성장이다.
Si 본체, 산화막, 계면 박리는 위치와 기구를 구분하고 동일한 사건을 중복 집계하지
않는다. 현재 실제 계산에는 산화막과 도펀트가 없다.

## 확률 이력 구현

`solver_v1/silicon_crack_records.py`는 기존 결정론적 생성 행렬에 세 이력 표지를
붙인다: 아직 형성되지 않음, 형성됐지만 주 사건은 미확인, 주 사건 확인됨.
실제 회복·닫힘 경로를 포함한 원래 동역학을 유지한다.

    P_form(t) = Pr(t까지 균열 형성이 한 번이라도 있었음)
    P_main(t) = Pr(t까지 비회복 개시가 확인됐음)

두 이력 확률은 더하지 않는다. P_form-P_main은 형성됐지만 아직 주 사건이
확인되지 않은 이력 질량이며, 최종적으로 회복할 확률과 다르다. 현재 균열의
점유 확률도 별도로 계산한다. 형성 집합과 주 사건 집합은 독립적인 구조·역학
검증으로 제공해야 하며, 후자는 전자에 포함돼야 한다.

지속 시간을 조건으로 쓰려면 상태에 후보의 경과 시간이나 필요한 이력을
추가해야 한다. 순간 구조에 미래를 미리 알고 붙인 표지를 입력하면 안 된다.
이번에는 실제 Si 확인 시간이나 그 시간 경계를 구현·보정하지 않았다.
거리 기준, 경험적 손상률, 영구 비가역 가정을 새로 넣지 않았다.

## kBT에서 검증할 것

검증 대상은 열항을 쓸 좌표·에너지 단위·고전 열욕 근사·축약 동역학이다.
볼츠만 상수를 적합하는 것이 아니다. 300 K의 kBT는 0.025852 eV다.
강한 결합은 에너지와 허용 자유도, 상관된 움직임에 반영한다. 동일한 총에너지
F를 f=F/N으로 표현하면 열항도 kBT/N, 이동도도 N M으로 환산해야 같은
확률 생성자를 나타낸다. 이것은 실제 온도를 바꾼다는 뜻이 아니다.

강한 결합이 있다는 이유만으로 kBT가 사라지거나 작아지는 것은 아니다.
다만 원자 전체의 고전 평형 분포를 쓰는 것과, 몇 개의 균열 좌표에 같은
확산식을 쓰는 것은 검증 단계가 다르다. 숨긴 원자 좌표를 적분한 자유에너지에는
그 구속과 엔트로피가 들어가야 한다. 비선형 집단 좌표라면 적분 측도의 변화도
확인해야 한다. 이동도와 열잡음의 관계, 관성·기억효과를 무시할 수 있는 시간
범위도 따로 검증해야 한다. 이번 Cartesian 항등식 통과만으로 Si의 축약
과감쇠 확률 방정식을 승인하지 않는다.

이번 실제 에너지 계산은 기존 MACE-MP-0b3 중성 참고 모델을 사용했다.
360개 순수 Si 원자 중 216개가 자유롭고 144개는 고정돼 있다. 자유 Cartesian
좌표는 648개다. 새 베셀 재료 후보의 열평형을 인증한 결과가 아니다.
모델 SHA256은 다음과 같다.

    2f2be696351ac9e94fbe01cdfb6f017679acdbd2db7645209ef55fec9826b012

두 시작 구조는 처음 8%와 10%를 거쳐 돌아온 8%이며, 고정 그립 위치가 동일하다.
두 구조의 중점을 기준으로 각 자유 Cartesian 성분을 ±3 Å 안에 두고 모든
원자 간 거리는 1 Å 이상으로 제한한 동일한 계산 영역을 사용한다. 이 영역은
건전 상태의 물리적 basin 또는 균열 판정 집합이 아니다. 영역 폭의 민감도는 미검증이다.

고전 300 K, pCN 제안 크기 0.35, 고정 seed 두 개, 각각 예열 16단계와 저장
48단계다. 거절한 뒤의 반복 상태도 저장한다. 실제 새 에너지·힘 평가 130회가
787.523초에 완료됐다. MC 단계는 물리 시간이나 균열 횟수가 아니다.
새 MD와 DFT는 0회다. 시작 시 가용 메모리 10,952,032,256 byte가 기존 보호선
6,000,000,000 byte를 넘었다. 과거 메모리 중단 기록은 덮어쓰지 않았다.

## 경계가 있는 열적 항등식

Cartesian 측도에서 pi(r)∝exp(-U/kBT)이고 벡터장 g가 계산 영역의 모든 경계에서
법선 통량 0이면, 부분 적분으로 다음 식을 얻는다.

    <g·grad U> = kBT <div g>

`silicon_thermal_identity.py`는 상자 경계 인자와 원자쌍 거리 경계의 매끄러운
인자를 모두 미분해 g를 구성한다. 자유 좌표의 총에너지 힘을 사용하며 고정
그립 반력은 식에 넣지 않는다. 유한 영역에서 경계항 없이 사용하는
<x·grad U>=d kBT는 일반적으로 맞지 않는다. 상자 인자를 넣었어도 원자쌍
경계의 미분을 빠뜨리면 오차가 남는다.

독립적인 비선형 수치 적분, 여러 원자쌍 경계의 좌표 차분, 경계항 누락 대조를
통과했다. 실제 짧은 체인으로 얻은 비율 온도 진단은 254.02 K와 284.86 K다.
이는 실제 물리 온도나 새 보정 계수가 아니다. 자기상관과 초기화 편향이 남은
짧은 체인의 오차를 온도 변화로 해석하지 않는다. 현재 결과로 재료의 열항을 승인하지 않는다.

기존 양자 조화 민감도 검사에서는 300 K 일부 모드의 분산 차이가 약 37%였다.
이를 모든 모드에 같은 유효 온도를 적용해 고칠 수 있다고 가정하지 않는다.
비선형 분포, 양자 민감도, 시간 상관과 외력 응답은 각각 별도 검증이다.

## 검증 및 남은 연구

관련 검사 52개가 8.60초에 통과했고 새 검사 17개를 포함한다. 최초 검사에서는
한 기하 예제의 활성 경계 원자쌍 기대 개수를 2로 잘못 적었다. 실제 3임을
확인해 기대 개수를 고쳤고, 미분식과 허용오차는 변경하지 않았다.
전체 솔버 회귀는 1,132개 검사와 6개 하위 검사가 2,278.47초에 통과했다.
앱 검사는 최초 166개와 하위 검사 3개가 통과했으며, Tcl 환경 오류가 난
23개를 승인된 환경에서 다시 실행해 모두 통과했다. 한 번의 전체 실행으로
189개가 통과했다고 보고하지 않는다. desktop smoke도 기존 평형값을 확인했다.
첫 실패와 환경 오류, 실제 검사 시간·원래 로그 해시는 TEST_RESULTS.json에 보존한다.

실제 Si의 균열 집합, 비회복 확인 구간, 수렴한 비선형 자유에너지, 이동도와
기억효과, 물리 초/Hz, 개시 확률과 수명은 아직 확보하지 못했다. Al/UI/생산
에너지와 물리 시간 설정은 보존한다.

다음 연구는 공간 형상과 국소 응집 응답을 대조하고, 비선형 샘플링의 예열·
자기상관·basin 탐색을 개선하는 것이다. 회복 시간 분포와 실험 하중 조건을
확보해 비회복 확인 구간을 정해야 한다. 고정 하중의 열평형 검사는 주기 하중의
동역학 검사를 대신하지 않는다.

열 샘플링은 서로 다른 초기 구조에서 같은 관측량의 분포가 일치하는지,
예열·길이·제안 크기·계산 영역을 바꿔도 결과가 유지되는지 확인해야 한다.
항등식 잔차도 자기상관을 반영한 오차와 함께 확인한다. 혼합이 막힌다면 실제
에너지 지형의 경로를 조사해야 하며, 샘플링 제안 이동을 물리적인 균열 전이로
세지 않는다. 그 다음에도 양자 민감도와 실제 시간 응답의 검증은 남는다.

## 참고 문헌의 범위

- [Kang·Cai의 Si 균열 핵생성 연구](https://micro.stanford.edu/~caiwei/papers/Kang_Cai_IJP_resubmitted.pdf):
  상대 변위의 방향과 공간 분포 분석을 참고한다. 거리값·강도·MD 시간을 이식하지 않는다.
- [Helfmann 외의 주기 구동 및 유한 시간 전이 이론](https://link.springer.com/article/10.1007/s00332-020-09652-7):
  사건과 commitment를 하중·시간 조건에 연결한다. 이 논문이 Si 균열 집합을 제공하지는 않는다.
- [Leimkuhler·Matthews의 분자 샘플링 연구](https://arxiv.org/abs/1203.5428):
  수치적 불변 분포 오차를 실제 모델의 타당성과 구별한다.
