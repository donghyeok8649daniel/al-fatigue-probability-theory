# v14 실제 완료 및 검증

## 이번 질문에 대한 결론

강한 고체 구속을 포함한 kBT의 수학적 정규화는 일관된다. 현재 Si 결과에 단순
조화 자유에너지와 일정한 이동도를 넣어 실제 균열 확률로 해석할 근거는 부족하다.
새 다차원 실제 에너지 검사는 국소 조화 제안분포가 실제 에너지 가중치를 제대로
대표하지 못할 수 있음을 보여준다. kBT를 임의로 줄여 맞추지 않는다.

## 실제 작업량

- 3개 기존 648차원 Hessian /4개 가정 온도: 새 선형대수 계산 12조건.
- 과거 SW 40 ps ×4기록: 원자료 상관·적분 재계산. 새 MD 0.
- 새 MP-0b3 전차원 평가: 64개 변위 + 기준 상태 대조 3회 = **67회**.
  50/300 K, 처음/복귀8%, 각16개 제안점. 같은 난수와 대칭 쌍을 독립 표본으로 세지 않는다.
- 첫 실행39회 /300.358초, 37/64점에서 시간 한도 종료. 원자료·코드 snapshot 보존.
- 재개28회 /214.485초: 나머지27점 + 복귀 출발 상태 대조1회. 종료코드0.
  기존37개 표본은 byte 복사 및 좌표 재검증으로 재사용했고 재평가하지 않았다.
- elapsed 합514.843초는 두 계산 실행의 경과 시간이며 물리 운동 시간이나
  측정된 CPU 시간 합이 아니다. 새 DFT0, 새 MD0, 실제 열평형 표본0.

## 실제 에너지와 조화 예측의 차이

| 상태 | 가정 온도 | 제안점 | DeltaU/kBT 범위 | 가중치 집중도 지표 | 가장 큰 상대 가중치 |
|---|---:|---:|---:|---:|---:|
| 처음8% | 50 K |16| -3.35698 ~ 2.83299 |3.62787|40.97%|
| 처음8% | 300 K |16| -8.54156 ~ 5.19373 |2.04279|53.97%|
| 복귀8% | 50 K |16| -4.24727 ~ 4.08425 |2.44740|59.43%|
| 복귀8% | 300 K |16| -11.08183 ~ 13.39743 |1.06459|96.87%|

DeltaU는 U_actual-U_quadratic이며 원자당 값이 아니라 시편 총에너지 차이다.
가중치 집중도는 (sum w)^2/sum(w^2), w=exp(-DeltaU/kBT)다. 이것을 독립 표본의
통계적 ESS, 실제 평형 점유율, 균열 확률 또는 장벽으로 해석하지 않는다.
50 K는 고전 제안분포의 수학적 대조이며 실제 저온 Si의 핵 양자 효과를 무시한
물리적 열평형 결과가 아니다. 이 데이터에서 자유에너지 추정치를 채택하지 않았다.

## 검증 결과

- 새 핵심 수학 구현: **10 pytest 통과 /6.65초**. 기록은 TEST_RESULTS.json.
- 부분37점의 독립 산술·SHA 검산: **427개 통과**.
- 최종64점의 독립 산술·SHA 검산: **711개 통과**.
  이 둘은 중복 항목을 포함하므로 1138개의 독립 시험으로 합산하지 않는다.
- 실제 에너지 및 조화 잔차 재계산 오차0, 고정 grip 변위0,
  전체 기울기 잔차 노름의 재검산 최대차4.44e-16 eV/A.
- 독립 Gaussian 에너지 항등식 오차4.09e-14 eV,
  antithetic 중심 항등식 오차1.12e-16 A.
- 기준 상태 재평가 에너지 차0, 최대 힘 차2.23e-16 eV/A.
- 고전/양자/과거 SW 비교 그림 thermal_validity.png를 직접 열어 검수했다.
- 최초 Git 바이트 검사는 기존 probability_pde_2d.py의 Windows CRLF/Git LF 차이로
  실패했다. 원래 커밋과 내용이 정확히 같음을 확인하고 이 파일의 두 표현만
  명시적으로 기록했다. 기존 생산 소스는 수정하지 않았다. 과학 원자료는 계속
  정확한 바이트 해시로 검사한다. 최초 manifest는 원본 작업 폴더 캐시에 보존했다.

보고서의 전체 식·범위·문헌은 README.md를 따른다. 최종 결과는
full_dimensional_completed/summary.json과 completed_replay.json이다.
full_dimensional_probes는 첫 부분 실행이며 실패 기록을 완료본으로 바꾸지 않는다.

## 아직 하지 않은 것

현재 MP-0b3 시편의 비선형 canonical 분포 샘플링, basin 혼합 확인, 실제 열평형
공분산·시간 상관·약한 외력 응답, 물리 이동도와 초/Hz 보정은 미완료다.
첫 균열 상태 B와 실제 개시 확률도 미확보다. 이번 결과는 적용 타당성 감사이며
Si 재료 채택이나 피로 수명 검증이 아니다. Al/UI/생산 코드를 변경하지 않았다.
