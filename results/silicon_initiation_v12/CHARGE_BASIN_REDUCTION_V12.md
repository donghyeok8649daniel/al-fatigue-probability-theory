# 빠른 전하 축약과 최초 개시 경계

## 공통 지배방정식 안에서의 문제

이번 검사는 기존 결정론적 확률 generator를 그대로 사용한다. 실제 Si 에너지,
전하 전이율, 도펀트별 개시 경계 또는 물리 clock을 새로 주지 않는다.
전하를 빨리 평균낼 수 있는지와 최초 개시 경계를 어떻게 줄이는지는 별도다.

고정 공간 격자에서 L = L_slow + nu K라 하자. K는 각 위치의 전하 전이,
nu는 합성 전이율 척도다. 주어진 개시 집합 B에 처음 들어간 질량을 collector에
보존하면 intact 부분은 L_AA = (L_slow)_AA + nu K_AA로 진화한다.
여기서 A는 B의 여집합이다. K_AA는 일반적으로 보존 행렬이 아니다.

한 위치에서 서로 연결된 빠른 전하 상태 중 하나라도 B에 포함되면, 그 위치의
잔존 전하 블록은 B로 질량을 잃는다. K_AA에 보존 영모드가 없으면 nu->infinity에서
해당 위치는 빠르게 흡수된다. 살아남은 전하 가중치를 다시 합1로 정규화해 이 손실을
지우면 원래 최초 통과 법칙과 달라진다. 유한한 sink k를 평균내는 이전 v9 검사는
k/nu가 작은 경우이며, 무한 흡수 경계의 이 극한을 자동으로 보장하지 않는다.

## 정확히 풀 수 있는 6상태 대조

공간 위치q=0,1,2와 전하 상태0,1을 쓴다. 공간 이웃 이동률은양방향r=0.4,
전하 전이는0->1에nu*p,1->0에nu*(1-p)다. B는(q=2,전하1) 하나다.
처음에는q=0에서 전하 평형(1-p,p)으로 시작한다. p는 전하 점유확률이며
도펀트 원자분율이나 Si의 실제 carrier 농도가 아니다.

이 조건의 평균 최초 도달 시간은 다음 닫힌식이다.

    T = 3/r + 3(1-p)(nu^2+3nu*r+r^2) / [nu*p*(nu+r)*(nu+3r)]

nu->infinity일 때T->3/r=7.5이고, 초과 시간은3(1-p)/(nu*p)+O(nu^-2)다.
따라서 경계에서 빠른 척도는nu 하나가 아니라nu*p다. p가 매우 작으면
전하 전이율nu가 커도 개시 상태에 도달하는 과정은 느릴 수 있다.
정확히p=0이면 시작한 전하0 집단은 닫힌 비흡수 집단이 되어 유한T가 없다.

공간 이동을 끄고(q=2,전하0)에서 시작하면 정확한 생존은exp(-nu*p*t)다.
전하를 조건부 평형으로 정규화하는 방식은 이 실제 경계 손실을 제거해서는 안 된다.

실제 실행: p=0.02/0.2/0.8,nu=0.01..100000의24행렬/120저장시점,
경계 닫힌식27대조. 질량 잔차 최대2.30822e-11, 독립 Padé/Krylov 차이
5.99520e-15. 평균시간 닫힌식 재계산의 최대 절대 차이1.30967e-10 model time.
관련 원자료는charge_basin_limit 및closed_form_replay.json에 있다.

예를 들어nu=100에서p=0.02의T는8.96417, p=0.8의T는7.50747이다.
같은 빠른 전이 척도라도 경계 점유가 다르면 최초 도달 지연이 다르다.
이는 합성 모델의 정확한 결과이며 B/P/As/Sb의 실제 순위가 아니다.

## 실제 Si로 넘어가기 전에 필요한 조건

- 각 고정 화학배치와 전하 상태에서 intact/전이/initiated 영역을 먼저 정의하고
  경계의 물리적 의미와 수렴을 확인해야 한다. 잠깐 늘어난 이웃 거리만으로 대체하지 않는다.
- 전하 축약 뒤 서로 다른 원인별 B의 공간 투영이 겹치면 원인을 중복 흡수시키지 않는다.
  빠른 경계 블록의 최초 도달 분할률도 계산해야 한다.
- 이 결과는 고정 공간 격자의 극한이다. 공간격자 축소로 이동률이커지면
  nu와의 상대척도를 다시 확인해야 한다. 극한의 순서를 자동 교환하지 않는다.
- 동결된 도펀트 배치 혼합, 빠른 전하 전환, 산화/수산화 반응은 서로 다른 상태 변화다.
  모두 같은 결합 확률 법칙에 들어갈 수 있으나 자료 없는 전이율을 만들지 않는다.

누출 검사 수정 뒤 기존 v9 전하 연구 전체도 새로 실행했다. 기존 결과의4개CSV와
summary JSON,총5개파일이 byte 단위로 같았다. 이는 새 guard가 유효한 기존
합성 계산을 바꾸지 않았다는 회귀 증거이며 재료 보정 또는 물리 시간 검증은 아니다.
