C adapter v1.1: A 기하·일 감사와의 교차 검토 및 수정
2026-10-18 KST / one-axis-1.1 / 로컬 준비만

v1의 면적/gauge guard에 포함될 수 있던 해석을 수정했다. 기존 확률 관측과
동일 P_n trial/단일 commit 규약은 유지한다. 원모형/생산 코드/물리값은 변경하지 않았다.
현행 소스는 이 v1_1 폴더의 독립 파일이다. 상위 outputs의 v1 소스와 영수증은
첫 버전의 이력으로 남기며 v1.1의 기하/provenance guard로 사용하지 않는다.

직접 대조한 A 근거
원래 solver/기존 MD/PDE/Bessel/LJ/fit는 다시 읽거나 실행하지 않았다.

수정 1. 일-유효 정규화와 실제 기하를 구별
원래 eps_x=h*/a0*, G_phys=r E0[W*-f*h*], f*=kappa sigma_x/E_x를 같은
축 가상일로 연결하는 조건부 정규화는
  Veff=r E0 kappa a0*/E_x,
  Aeff=Veff/(L0 a0*)  [a,s의 공통 L0 조건]
이다. A의 per-representative 식에 대해 여기서 r는 별도로 선언한 energy
multiplicity다. 동일 collective q의 에너지 기여라는 추가 조건과 counting
출처가 필요하며 독립 복제/mesh 개수를 자동 대입하지 않는다.

Veff/Aeff는 실제 V_geom/A_int/A_loaded를 알아낸 값이 아니다.
v1의 volume_m3, interface_area_m2, axial_loaded_area_m2를 다음 필드로 분리했다.
  actual_geometric_volume_m3
  actual_interface_area_m2
  actual_loaded_area_m2
  actual_axis_gauge_length_m (= H_actual, 독립 입력)
derived work_effective_volume/area는 다른 출력 필드다. Aeff를 실제 loaded
또는 interface 면적 필드에 복사하거나 geometry를 equality에 맞춰 조정하지 않는다.

v1의 A_loaded*L0*a0*/V=1 조건은 제거했다. L0*a0*는 모델 기준 간격이며
실제 axis gauge length를 이 값으로 설정하거나 같아야 한다고 요구하지 않는다.
별도로 uniform loaded prism 기하를 호출자가 선언한 경우에만
  A_loaded*H_actual/V_geom=1
을 검사한다. 일반/비균일 기하에 이 prism 항등식을 강제하지 않는다.
이 prism 검사도 실제 strain mapping이나 계면 coefficient 검사를 대신하지 않는다.

독립 입력 V_geom이 있으면 Veff/V_geom과
  residual_V=E_x*V_geom-r E0 kappa a0*
를 보고한다. 불일치를 guard로 남기며 실제 V나 E0/r를 자동 조정하지 않는다.
현재 tolerance는 adapter의 명시적 대수 비교 허용오차다. 실험 불확도에 의한
물리적 합격 판정으로 해석하지 않는다. 물리 불확도 audit는 별도 미정이다.

수정 2. normal/slip 두 계수 검사와 실제 검증 상태 분리
실제 방향 l,n,m과 실제 A_int,V_geom, 공통 L0가 모두 선언되고, 단일 계면의
jump=n da_phys+m ds_phys만 채택한 axial strain을 공급한다는 조건일 때만
  alpha=l dot n, beta=l dot m,
  (A_int/V_geom)*alpha^2 = 1/(L0*a0*),
  (A_int/V_geom)*alpha*beta = chi/(L0*a0*)
를 각각 비교한다. unit l,n,m과 n dot m=0도 입력 guard로 검사한다.
수치 비교는 두 계수에 L0*a0*를 곱해 각각 1과 chi에 대조한다.
chi=0에서도 나눗셈으로 slip 조건을 소거하지 않는다.

실제 n,m/geometry 또는 이 단일 계면 가정이 없으면 두 검사 checked=false,
consistent=false다. 다른 bulk 기여를 가진 일반 기하를 틀렸다고 판정하는
것이 아니라 이 특별 예제의 검사 범위 밖이라는 뜻이다.
한 계수만 맞고 다른 계수가 다르면 불일치 항목을 구분해 반환한다.
실제 geometry를 생성하거나 회전/chi/면적을 맞추는 역문제는 풀지 않는다.

수정 3. 동일 모델/파라미터/에너지 counting 묶음
EnergyBundleReference는 energy_model_id, parameter_fingerprint,
energy_counting_source의 세 필드다. model/scales/cell 선언 각각에 붙인다.
E0,a0*,kappa,chi와 representative energy counting이 같은 묶음이라는 호출자의
선언을 기록한다. 채워진 값이 서로 다르면 validate 단계에서 즉시 거부한다.
누락은 null로 남기며 무차원 관측은 가능하지만 Veff/Aeff 산출과 실제 backend
진화 호출은 차단한다. intended original instance의 값을 역사적 기본값으로 채우지 않는다.
E0 basis는 per-original-representative로 명시하며 aggregate E0를 r와 다시
곱하지 않도록 다른 basis를 거부한다. 실제 counting의 정당성은 외부 감사 대상이다.
E_x의 방향/온도/구속 조건 출처는 별도 필드로 둔다.

이 문자열 동일성 검사는 원본 파일을 읽거나 parameter hash를 다시 계산한
검증이 아니다. bundle metadata의 basis=caller_declaration_only,
independently_verified=false, original_parameter_fingerprint_recomputed=false다.
adapter 전체 선언을 계산한 declaration_fingerprint와 실제 원모형의
parameter_fingerprint는 용도가 다르며 하나로 바꾸지 않는다.

수정 4. 대수 일치로 physical ready를 승격하지 않음
work_normalization_status의 one_axis_declared_checks_consistent는 필요한
명시 선언과 해당 계수 비교가 일치했는지만 나타낸다. caller_work_audit_accepted도
호출자 진술이다. 실제 geometry/provenance의 독립 검증이 아니다.
physical_work_ready는 이 adapter에서 항상 false이며 기존 함수
require_physical_work_ready는 실제 승인자 역할을 하지 않고 항상 차단한다.
대수 검사 용도의 require_one_axis_declared_checks_consistent를 별도 제공한다.
모든 선언과 수치 비교가 맞아도 actual_normal_slip_geometry_independently_verified,
physical solver/full3D/spatial readiness를 true로 바꾸지 않는다.

나머지 계약
원래 eps/opening/well-memory/wrapped 분해, 생존 무정규화 모멘트/조건부 평균,
누적 opening 흡수량과 commit 증가량, raw weak/tensor stress 거부,
동일 P_n trial/한 번 commit 및 외력 중복 금지는 v1과 같다.
theta/mobility/물리 시계와 확률 지배식/유량/실제 개시경계는 계산하지 않았다.
G 에너지 배율/수동 단위변환/독립 복제의 구별은 A 감사 범위를 유지한다.
마이크로 에너지와 물리 응력을 연결하는 이번 국소 protocol을 실제 Cphi
공간 solver, MPSA-W operator나 full3D bulk tangent의 구현으로 부르지 않는다.

새 경계 검증 범위
7개 새 test method: 면적/gauge/ready 분리, 과거 면적 equality만으로 통과 금지,
normal/slip 불일치 구별, model/fingerprint/counting 혼합 거부, 누락 provenance
차단, 실제 V 불일치 보존, 선언한 prism에서 실제 gauge만 사용.
추가 8개는 새 validate/metadata가 observe와 trial/commit의 모든 진입점에 영향을
주므로 필요한 v1 인터페이스 회귀다. 변경과 무관한 기존 과학 QA 반복이 아니다.
추상 유리수/단위 label fixture만 사용하며 실제 물리값이나 실제 solve가 아니다.
코드·입력 snapshot, 자기 child PID 25초 watchdog/최대30초로 한 번 실행하고
실제 횟수/exit/wall/CPU는 INTERFACE_VERIFICATION_RUN.json에 기록한다.
v1은 과거 1회였고, v1.1 성공 1회면 C의 전체 인터페이스 실행 누계는 2회다.

다음 단일 단계
총괄이 v1.1의 field mapping과 A 감사 조건을 검토해 소유 모듈 경로로 통합한다.
실제 활성화에는 동일 원래 model/parameter/counting 출처와 독립 기하 자료,
normal/slip 양 계수의 범위/불확도, 물리 시계·확률 사건 mapping이 필요하다.
원격 branch allocation은 있으나 C의 clone/checkout/publish는 수행하지 않는다.
