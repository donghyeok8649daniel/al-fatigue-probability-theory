# Bundled Korean build fonts

The two font files in this directory preserve the Noto Sans KR glyph outlines
already embedded in an earlier build of this manuscript. Their Unicode character
maps were reconstructed solely to make the XeLaTeX build reproducible in minimal
environments that do not provide a Korean system font.

The original Noto fonts are distributed under the SIL Open Font License 1.1:
<https://openfontlicense.org/open-font-license-official-text/>.

These fonts affect document rendering only; none of the scientific equations or
numerical results depends on them.
