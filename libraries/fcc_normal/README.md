# Archived FCC Normal-LJ Library

This directory preserves the three-dimensional FCC normal-Lennard-Jones work that was previously developed in the repository root.

It is **not part of the active research mainline**. The active theory is deliberately restricted to a one-dimensional normal-spacing model using $P(a,t)$ and a fixed generalized Lennard-Jones interaction.

The FCC work is retained because its lattice sums, calibration checks, Cauchy-relation test, figures, and numerical results may be useful later for validation or comparison.

Nothing in this archive should be imported by the default active simulations or tests.

---

# 한국어 번역 — 보존된 FCC Normal-LJ 라이브러리

이 디렉터리는 이전에 repository root에서 진행했던 3차원 FCC normal-Lennard-Jones 연구를 보존한다.

이 내용은 **현재 활성 연구 mainline이 아니다.** 활성 이론은 의도적으로 $P(a,t)$와 고정 generalized Lennard-Jones interaction을 사용하는 1차원 수직 원자간격 모델로 제한한다.

FCC 연구의 lattice sum, calibration 검증, Cauchy relation test, figure 및 numerical result는 나중에 validation 또는 비교에 유용할 수 있으므로 삭제하지 않고 보존한다.

이 archive의 코드는 기본 active simulation이나 test에서 import하지 않는다.
