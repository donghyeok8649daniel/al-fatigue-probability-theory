# Research Outreach / Experimental Support

This branch collects materials used to seek academic collaboration, experimental access, specimens, and research support for the fatigue-initiation paper.

## Primary objective

The immediate goal is publication of the physics-based 1D fatigue-initiation model. The main current bottleneck is experimental validation rather than product commercialization.

## Target collaborators

- fatigue / fracture laboratories with cyclic testing capability
- materials laboratories working on single crystals, aluminum, superalloys, or micromechanics
- statistical physics / nonequilibrium thermodynamics researchers for theory review
- applied mathematics researchers for probability-evolution / first-passage formulation
- industrial partners for specimens, testing access, technical review, and later application studies

## Scientific message

The presentation should distinguish clearly between:

1. current theory and numerical results,
2. unresolved physics requiring review,
3. experimental validation requested from collaborators,
4. long-term FEM / desktop application / fatigue-tester / turbine-blade extensions.

The first outreach objective is not a large cash request. Preferred support is technical review, machine time, specimen access, joint experiments, and eventual coauthored validation.
